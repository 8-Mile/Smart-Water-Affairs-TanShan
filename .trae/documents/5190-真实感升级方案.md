# 5190 首页真实感升级方案（HDR 天空 + 精细资产 + 新机位）

## Context

当前 5190 首页的水面已改为解析波浪着色器，但整体仍偏"程序化低模 + 手绘天空"：建筑是纯色盒体拼装、树是几何簇、堆场只有单一颜色、天空是 Canvas 渐变、渲染管线没有真实 IBL/后处理/平面反射。用户要求按"真实 HDR 天空"路线，把树、建筑、堆场全部精细化，允许更换默认机位，不接受继续逐项微调。

本方案给出一次性落地的技术路线：**完全保留 CAD 坐标与地标锚点**，只替换表现层资产与渲染管线；Blender 负责"有形体"的精细建模，three.js 负责地形、水面、天空、实例化、反射与后处理。

## 调研结论（已核实）

- Blender 5.2.2 已安装：`/Applications/Blender.app/Contents/MacOS/Blender`（CLI 可用）。
- 已有可复用的 Blender 资产管线：`frontend/modeling/harbor/refine_port.py`、`refine_buildings.py`、`inspect_asset.py`；约定为"原点在基底中心、Z 向上、`export_yup=True`、按材质 merge 后导出 GLB"。
- 现有 GLB 共 20 个、仅 948KB，材质全是纯色 Principled BSDF；树只有 3 个低模 GLB（13–23KB），且仓库内没有树的生成脚本。
- 贴图只有 `ore-grain.jpg` / `ore-normal.jpg` 两张。
- three 版本 0.186.1，`Reflector`、`Water2`、`Sky`、`EffectComposer`、`UnrealBloomPass`、`GTAOPass`、`SMAAPass` 均可用。
- 默认桌面机位写死在 `L1WaterScene.vue`：FOV 8.53°、距离 323.6、pitch 16.51°、target(-20.34,0,60.26)；`?focus/?zoom` 仅用于内部核查。
- 渲染器已开 `NeutralToneMapping`、exposure 1.15、阴影；**没有后处理**。
- 天空是 2048×1024 Canvas 等距柱状图 + PMREM；雾 `#d5e5e5` 330–1000；主光 `(64,104,44)`。
- 外网可用：Poly Haven HDR 下载返回 200（1k 纯天空约 1.4MB），AmbientCG 可访问；three 官方示例贴图路径已 404，不能依赖。
- 场景范围约 x∈[-47,46]、z∈[-48,68]，海面从岸线向外 142 单位。

## 技术路线判断

| 对象 | 由谁完成 | 做法 |
|---|---|---|
| 天空 / 环境光 | three + HDR | 下载 CC0 真实 HDR（2k），`RGBELoader` + PMREM 作为背景与 IBL；按主光方位旋转 HDR 太阳 |
| 水面 | three（自定义 shader） | 解析波浪保留，新增**半分辨率平面反射 RTT**（倒映船、码头、岸线、天空）+ Fresnel 混合 |
| 建筑（12 个） | Blender | 参数化立面：窗带/竖挺/门洞/雨棚/女儿墙/屋面设备/检修梯；PBR 混凝土/金属/玻璃 |
| 树（3 类 + 灌木） | Blender | 树干+分枝+多层 alpha 叶簇交叉面片；4 个变体，three 侧 InstancedMesh |
| 堆场 / 煤堆 | three | 保留现有 `stockpile()` 形体并加脊线细节，换煤堆 PBR（albedo/normal/roughness） |
| 道路 / 场坪 / 地面 | three | 沥青、混凝土、泥土 PBR 贴图平铺，保持现有 CAD 开槽与明沟逻辑 |
| 后处理 | three | EffectComposer：RenderPass → Bloom（弱）→ SMAA → OutputPass |
| 默认机位 | three | 改为更低、更长焦段之外的"广告级"3/4 透视，允许重构图 |

**不采用"图片转 3D"**：本机没有可离线运行的图生 3D 服务，Tripo/Rodin 一类需要外部 API Key，且输出为不可控的稠密网格，无法保证与 CAD 尺寸、落位、面数预算一致。改用 Blender 参数化建模 + CC0 PBR 贴图，确定性、可复现、可版本管理。若后续提供图生 3D API，可作为"远景装饰物"补充，不用于主设施。

## 实施步骤

### 1. 资源准备（不进 git 的大文件放 `frontend/public/tanggang/`）

- 下载 2k CC0 HDR 到 `frontend/public/tanggang/environment/`，优先"晴朗/薄雾 + 太阳高度≈50°"，例如 Poly Haven `kloofendal_48d_partly_cloudy_puresky`（按实际可用性选）。
- 从 AmbientCG 下载 CC0 PBR：煤堆、沥青、混凝土、压型钢板、玻璃、树皮、草地。每套保留 1k 的 albedo/normal/roughness（ORM）。
- 记录来源与许可到 `docs/migration/evidence/5190-realism-v4/asset-sources.md`。

### 2. 天空与光照（`L1WaterScene.vue`）

- 用 `RGBELoader` 加载 HDR，`PMREMGenerator` 生成环境图；`scene.background = hdr`、`scene.environment = pmrem`。
- 用 `scene.backgroundRotation` / `environmentRotation` 把 HDR 太阳对齐到主光方向 `(64,104,44)`（仰角≈53°、方位≈34.5°）。
- 主光颜色改为中性偏暖白、强度按 HDR 重新标定；补光降低，避免"两套天空"。
- 雾色从 HDR 地平线取样（离线取一个近似值即可），保持 330–1000；保留 Canvas 天空作为加载失败回退。
- 删除/降级现有 Canvas 云的绘制，避免与 HDR 云重复。

### 3. 水面平面反射（`harborRelief.ts`）

- 在 `buildHarborRelief` 内新增反射渲染目标（1024×576 或 0.5× 画布）与镜像相机：
  - 以海平面 y≈0.055 镜像主相机，使用斜裁剪近平面避免水下几何；
  - 只渲染反射需要的层（天空、船、码头墙、岸线、建筑、树带），水面自身排除；
  - 每帧或隔帧更新（静止时可缓存，相机移动时更新）。
- 自定义海面 shader 增加 `uReflection`、`uReflectMatrix`：按屏幕投影 UV 采样反射纹理，用波浪法线做 UV 扰动，按 Fresnel 与解析天空混合；解析天空反射保留作为远景/降级回退。
- 反射纹理按距离做 LOD 模糊，避免远景噪点。

### 4. 树木重建（Blender + three 实例化）

- 新增 `frontend/modeling/harbor/refine_trees.py`：
  - 树干、主枝、次枝用锥台/圆柱；树冠用 4–6 张交叉 alpha 面片 + 2–3 层球形叶簇混合；
  - 生成 4 个变体 + 1 个灌木，输出 `tree-*.glb`（单株 ≤ 300KB）；
  - 叶簇贴图用脚本生成 512² RGBA（透明背景），或用 CC0 树叶贴图。
- three 侧把现有程序化树批替换为 `InstancedMesh`：沿用现有树带点位与避让逻辑，按变体分组、随机缩放/旋转；近景开阴影，远景只保留实例。

### 5. 建筑精修（Blender 参数化）

- 新增 `frontend/modeling/harbor/harbor_kit.py`：`mat_pbr()`、`window_grid()`、`facade()`、`roof_kit()`、`export()`。
- 重建默认视角可见的建筑：除尘泵房、污水处理场、智慧中心、办公楼、食堂、检修间、仓库、车间、生态泵房、一体化处理、皮带机廊道、洗车台。
- 关键立面：分格玻璃幕墙（竖挺+横梁+真实玻璃材质）、门洞与雨棚、女儿墙与压顶、屋面机组/风机/楼梯间、外挂钢梯与栏杆、雨落管。
- 尺寸、原点、落位保持现有 GLB 约定；每个 GLB 内按材质合并，控制 draw call。
- 材质：混凝土/压型钢板/玻璃/深色金属从 PBR 贴图库取，玻璃用低粗糙度 + 环境反射。

### 6. 堆场、道路与地面

- `stockpile()` 增加脊线/推土机压痕的低幅法线细节；材质换成煤堆 PBR（albedo + normal + roughness），保留现有 UV。
- 场坪、道路、土面替换为沥青/混凝土/泥土 PBR 平铺；保留 FB499 开槽、明沟、树带净空等现有逻辑。
- 海岸线、码头墙、系缆桩、护舷维持现有几何，补金属/混凝土材质。

### 7. 新默认机位与后处理

- 桌面机位改为 3/4 透视：FOV 24–28°、pitch 18–22°、yaw 6–8°，距离按 8 个堆场 + 两船 + 东侧建筑重新拟合；保留 `?focus/?zoom` 与 `view=top` 核查入口。
- 移动端沿用现有自适应包围盒机位，只调整 FOV 与目标点。
- `EffectComposer`：RenderPass → UnrealBloom（threshold≈0.9、strength≈0.2）→ SMAAPass → OutputPass；移动端关闭 Bloom，保留 SMAA。
- 若帧率低于 45fps（headless 1672×941），反射降到 0.4×、Bloom 关闭，优先保相机操作流畅。

### 8. 验收与文档

- 截图：默认视角（1672×941、1920、2560）、低角度水面临近、东侧建筑近景、北侧树带近景；产出 `skysea-before-after.png` 新版。
- 性能：记录 FPS、draw calls、triangles、geometries、textures；与当前 192 calls / 1.35M triangles 基线对比。
- 回归：洗车台/人工湖/维修车间拾取、52 号船入画、FB499 开槽、明沟、手机 390×844 留白、旋转深度精度。
- `npm run build` 通过并还原 `frontend/components.d.ts`；更新 `docs/migration/evidence/5190-field-review-v3/progress.md` 或新建 `5190-realism-v4/progress.md`。

## 验证方式

1. `node`/`vite` 启动 5190，登录后打开 `/dashboard`，等待模型加载完成。
2. 截图默认机位与近景，人工核对天空倒影、建筑立面、树叶轮廓、煤堆材质是否与设计稿同层级。

4. 逐项回归拾取与既有验收项。
5. `npm run build`。

## 风险与边界

- 平面反射 + 后处理会使帧率下降 25–40%，需按实测降级；低端机可退化为解析天空反射 + 无 Bloom。
- 2k HDR 与多套 PBR 会增加首屏体积（预计 +8–15MB），需要预加载/渐进加载提示。
- Blender 重建资产会改变现有 GLB 外观，需保持尺寸/原点不变，避免落位漂移。
- 真实 HDR 的云量与太阳方位受可用 CC0 资源限制；若找不到匹配"晴朗薄雾"的 HDR，则用 HDR 做 IBL、背景改用与 HDR 同源的降饱和版本。
- 仍然做不到照片级：低模场景的"木桶效应"、无路径追踪/无实时 GI；本方案目标是"高保真写实风格"，不是影视级。
