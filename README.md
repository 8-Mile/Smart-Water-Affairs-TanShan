# 唐山港智慧水务 DEMO

京唐港区 51、52 号泊位智慧水务单机演示。前端为 Vue 3 + TypeScript + Vite + Pinia + Naive UI + ECharts，所有业务数据由本地种子与浏览器 `localStorage` 驱动，不请求 `/api`，启动 Vite 即可完整演示。

## V3.7 设备统一工作台（2026-11-17）

原系统新增单设备连续操作页：http://localhost:5174/operations/asset-workspace?assetId=asset-p002。
包含测点与规则健康、告警确认、原工单办理、人工巡检、异常转单、设备履历与档案核查。
业务动作沿用原数据和权限；不自动派单，不下发PLC/SCADA控制，不新增侧栏菜单。
详情请见 docs/product/v37-unified-asset-workspace.md。

## V3.6 设备与水资源业务衔接（2026-11-17）

- 设备台账选中设备后，可按相同 assetId 前往运行事件、工单、巡检、健康分析和设备档案；工单与巡检使用同一设备筛选。
- 在水源分配页保存WS草稿后，可以选择“按此编号核算成本”；成本页必须人工确认、按原始输入重新计算，不自动套用旧费用或替换其他草稿。
- 调蓄页可向四预预演传入降雨量，人工确认后重算；不代表工程池体、实际管线和模型参数已一致。
- 具体变更与边界：docs/product/v36-device-water-workflows.md。

## V3.5 业务工作台入口（2026-11-17）

当前原项目新增统一事件入口： http://localhost:5174/operations/events 。

侧栏按业务整理为七组：综合总览、运行中心、工艺监控、设备运维、水资源管理、分析中心、系统设置；业务页在内部 Tab 切换，保留原来的旧路由。事件中心在“全部事件”只汇总读取生产告警、业务提醒和智能巡查记录；业务办理继续由原告警/巡查/协同模块授权执行，不自动合并原始记录或创建工单。

设计与验收说明： docs/product/v35-navigation-event-center.md 。Git 基线为 V3.4，V3.5 继续在相同工程开发；不代表已经对接真实SCADA或数据库。

## 快速启动

环境要求：Node.js 20+、pnpm 10+。

```bash
pnpm install
pnpm dev
```

浏览器打开 <http://127.0.0.1:5173>。

`pnpm dev` 只启动 `@water/web`。演示不需要启动 `@water/api`，也不需要数据库、模型服务或外部网络。

## 演示角色

系统没有登录页和账号密码。进入页面后，在顶栏「演示角色」下拉框切换身份，菜单、按钮和命令校验会即时更新。

| 角色 | 关键能力 |
| --- | --- |
| 系统管理员 | 全部权限，含新增设备、演示场景切换与恢复、系统配置 |
| 管理者 | 工单验收/退回、岗位看板、查看诊断 |
| 值班运行员 | 创建/提交/取消工单、确认告警 |
| 运维人员 | 接单、提交处理结果、追加测点、挂接档案 |
| 水资源/环保人员 | 查看水资源与环保数据、创建工单 |
| 只读访客 | 仅查看工艺数据，所有写入入口隐藏，命令返回 `FORBIDDEN` |

默认演示用户为 `demo-user`（页面内显示为「演示用户（模拟）」），无默认账号密码。

## 演示场景

顶栏「演示场景」仅系统管理员可见，切换时会二次确认。当前场景的个人变更保存在本场景分组中，个人看板保留。

| 场景 | 用途 |
| --- | --- |
| 常态运行 SCN-NORMAL | 默认入口，设备平稳、告警处于日常水平 |
| 泵组故障 SCN-PUMP-FAULT | P-002 振动上升，演示健康诊断、趋势触阈与证据 |
| 降雨过程 SCN-RAIN | 雨水储量与回用负荷抬高，演示雨次分析 |
| 含矿污水波动 SCN-MINING | 含矿污水处理负荷与加药量波动 |

固定参考时刻为 `2026-11-14 08:00:00 +08:00`，所有趋势与时间线均围绕该时刻生成。

## D1-D5 演示路径

### D1 建档：AI 五步向导新增 P-003

1. 角色切换为「系统管理员」，进入「设备与运维 / 设备台账」。
2. 点击顶栏「问 AI」，输入：
   `在射雾器除尘系统新增一台3号供水泵，编号P-003，额定功率45kW、流量120m³/h、扬程60m。增加出口压力、电流、流量和运行状态四个测点。`
3. 点击「解析指令」，自动打开五步向导；依次「继续」→「继续」→「跳过（保存为未布置）」→「继续」→「确认创建」。
4. 创建成功后点击「查看设备台账」，搜索 `P-003` 可见，刷新后仍在。
5. 再次提交同一指令会被编号唯一性校验阻止，不会出现第二台设备；取消未提交的向导不会留下设备、测点或绑定。

### D2 档案诊断：健康评分与证据

1. 任一切换角色，进入「智能决策 / 健康与能效」，或直接访问 `/decision/health?assetId=asset-p002`。
2. 查看健康分、四因子明细（原值、警戒/危险阈值、风险值、扣分、来源）、趋势图与证据库。
3. 点击任意证据条目，右侧（或「查看证据与建议」抽屉）显示证据详情与引用位置。
4. 振动缺测时健康分显示「资料不足」，不会自动重加权成 100 分。

### D3 A2UI：生成、改图、保存与恢复

1. 角色切换为「管理者」，进入「数据分析 / AI 工作台」。
2. 输入「对比最近三次降雨南北储量并做成折线图」，点击「生成图表」。
3. 在右侧属性区把图型改为柱状、时间范围改为最近 2 次、点击「增加平均值」，提示条应显示「当前：柱状 · 最近 2 次 · 含平均值」。
4. 点击「保存看板」，页面记录 `v1`；刷新后可恢复，也可以到「我的看板」点击「打开」。
5. 输入「生成最近七天的用电量曲线」会被拒绝并提示 `MISSING_DATA`，因演示数据缺少 kW 电耗测点，不生成替代曲线。

### D4 告警转工单：建单、办理、验收归档

1. 角色「值班运行员」进入「设备与运维 / 告警事件」。
2. 打开「含矿污水加药量接近月度预算」，点击「生成工单草稿」，系统生成 `WO-2026-xxx` 并建立告警双向关联。
3. 点击「查看关联工单 →」，点击「提交待派单」。
4. 切换「运维人员」，打开同一工单，点击「接单开始维修」并填写负责人，再点击「提交处理结果」填写原因与措施。
5. 切换「管理者」，点击「验收通过并归档」；状态变为「已归档」，处理历史保留，并派生设备维保记录与设备履历。

### D5 角色与管理：拒绝越权、场景切换与复位

1. 角色「只读访客」访问 `/admin/roles`，会被重定向到「当前角色无权限」页。
2. 切换「系统管理员」，访问 `/admin/roles` 查看「角色权限矩阵」，菜单、按钮、命令三层权限一目了然。
3. 访问 `/admin/demo`，对「降雨过程 SCN-RAIN」点击「切换到此场景」并确认；再点击顶栏或面板中的「恢复场景」清除当前场景本地新增数据。
4. 页面右上角与 `/admin/demo` 都提供场景切换/复位入口。

## 数据与 localStorage 复位

本地演示状态使用以下键：

| 键 | 用途 |
| --- | --- |
| `tanggang-demo-role` | 当前演示角色 |
| `tanggang-demo-state-v1` | 各场景的设备、测点、绑定、工单、告警确认、审计、看板等本地状态 |
| `tanggang-demo-templates-v1` | 本地看板模板 |

复位方式：

1. 顶栏「恢复场景」：仅清除当前场景的本地新增数据，个人看板保留（仅系统管理员）。
2. 管理页 `/admin/demo` 的「恢复场景」：效果同上，并可导出/导入当前场景 UserState JSON。
3. 彻底复位：浏览器开发者工具中删除上述 `localStorage` 键后刷新，或清除该站点数据。

## 演示边界

- 不调用真实大模型：AI 指令由本地规则解析，A2UI 由本地生成器构造。
- 数据为演示模拟值，不是现场实测数据；趋势由固定种子生成，可复现但不代表真实设备。
- 不连接生产控制系统，不下发任何控制指令。
- 前端不请求 `/api`，无后端依赖；`apps/api` 仅保留原有单测，不参与演示运行。
- 验收归档仅代表流程确认，不会自动修改健康分、测点质量或历史监测数据。
