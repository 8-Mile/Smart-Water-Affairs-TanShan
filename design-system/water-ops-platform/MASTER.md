# 水务运管平台 · 设计语言 MASTER

> 版本 v1.1（2026-11-07，补充高度填充规则、设备树/骨架规范、异步插入入场与 forwards 状态冲突）· 适用 `frontend/`（Vue 3 + Element Plus + SCSS）
> 页面级规则放 `pages/<page>.md`，存在时优先于本文件。

## 1. 产品语境

- 类型：B 端运管（Operate 模式），中文界面；用户 = 领导 / 业务管理 / 值班运维。
- 场景：值班盯屏（告警→定位→派单闭环）、管理查阅（台账/统计/报表）。
- 设计优先级：**扫读效率 > 状态明确 > 视觉质感**。装饰永远让位于数据可读性。

## 2. 风格定位

- 风格：浅色玻璃拟态（Light Glassmorphism，政务浅蓝）。
- 实现基线：卡片/侧栏 `backdrop-filter: blur(14px) saturate(1.15)`；1px 半透明边框（`rgb(125 171 212 / 20%)` 级）；多层 Z 深度；浅蓝渐变表面。
- 硬约束：玻璃面上正文对比度 ≥ 4.5:1；支持键盘可见焦点；`prefers-reduced-motion` 下动效降级为静态。

## 3. 色彩

### 3.1 品牌与中性
| 角色 | 值 | 用途 |
|---|---|---|
| 主色 | `#1677ff`（EP primary，harbor 主题注入） | 主按钮、链接、选中 |
| 标题文字 | `#1b2a3d` | 页面/卡片标题 |
| 正文 | `#33415a` / `#314d78` | 菜单、表格正文 |
| 次要文字 | `#7890b0` | 表头、说明 |
| 弱提示 | `#9fb0c4` / `#94a7bd` | 占位、空态提示 |
| 页面背景 | 浅蓝渐变 + 固定背景图 | body |
| 卡片表面 | 白→浅蓝渐变磨砂 | 卡片/侧栏 |

### 3.2 状态色（必须用语义 token，禁止散落硬编码）
| Token | 语义 | 用法 |
|---|---|---|
| `--status-running` 绿 | 运行中/正常/已完成 | 色点+文字 |
| `--status-alarm` 红（现 `#ff3b5c` 系） | 告警/故障/紧急 | 色点+文字 |
| `--status-pending` 橙 | 待处理/待验收/预警 | 色点+文字 |
| `--status-info` 蓝（现 `#0e7ff0` 系） | 处理中/信息 | 色点+文字 |
| `--status-offline` 灰（现 `#94a3b8` 系） | 离线/停用/无效 | 色点+文字 |

规则：状态不得仅靠颜色传达（色点/色条必须配文字或图标）；装饰色（KPI 图标底、插画）降饱和，不得与状态红/橙同权重争注意力。

## 4. 字体与排版

- 字体栈：系统无衬线（PingFang/微软雅黑回退）；数字与英文用 Arial（工业看板惯例）。
- 数字：KPI/统计数字 `font-variant-numeric: tabular-nums`，多位数纵向对齐不错位。
- 字号层级：页面标题 16–18 / 卡片标题 13–14（600）/ 正文 13 / 辅助 12 / KPI 数字 ≥24。
- 行高：正文 1.5–1.625；表格行 1.4–1.5。
- 禁止为层级乱跳字号（12/13/14 三档之外新增需说明）。

## 5. 间距与密度

- 8px 基准网格；页面 gutter 12–16px；卡片 padding 16px；区块间距 12–16px。
- 密度两档（token 化）：
  - `density-standard`：页面主表格，13px / 行高 40px / 单元格 padding 10px 12px；
  - `density-compact`：弹窗与抽屉内表格，13px / 行高 36px / padding 8px 12px。
- 禁止出现第三套字号/行高组合。

### 5.1 高度填充（撑满不空白）

- 卡片被容器拉伸（`flex: 1 1 auto` / 等高行）后，内部必须且只能有一个「吸收剩余高度」区域：`flex: 1 1 auto; min-height: 0`，由它内部滚动或拉伸。
- 少量数据的网格用 `align-content: stretch` + `grid-auto-rows: minmax(<最小行高略大值>, 1fr)` 铺满，配合卡片内容垂直居中；禁止靠空块占位。
- 页面底部结构不一致时（父节点有「下属设备」、子节点没有），上下两块必须明确谁吸收剩余高度：本平台为「详情主卡吸收，主卡内容向下占满」。
- 验收口径：用 `getBoundingClientRect` 量"最后一块底部 vs 容器底部"，间距应 ≤ 16px（理想为 0）。

## 6. 圆角与阴影

- 圆角：`--custom-radius: 0.75rem`（卡片）；菜单项/标签 10px；按钮随 EP。
- 阴影：卡片 `0 5px 15px rgb(45 121 192 / 8%)` + 可选 `inset 0 1px 0 rgb(255 255 255 / 88%)` 高光；禁止重投影多层叠加。

## 7. 组件规范

- **侧栏**：210px 展开 / 70px 折叠；底部 menuBg.png 顶边 72px 羽化衔接；选中 = 白→浅蓝渐变胶囊 + 1px 浅蓝描边 + 左侧 3px 蓝渐变竖线；Hover 极淡蓝边框+浅蓝渐变。
- **KPI 卡**：图标 + 标签 + 大数字 + 迷你趋势；实时数据必须带"更新于 HH:mm:ss"，断链降饱和置灰（stale 态）。
- **表格**：斑马纹浅蓝系；表头 `#ecf5ff` 吸附；状态列用胶囊 tag（色点+文字+浅描边）；行可点击必须有 hover 态 + `cursor: pointer`。
- **批量操作**：数据表（告警/工单/台账）复选列 + 顶部操作条，禁止只有单行操作。
- **空态**：统一 `noData.png`（透明底）——el-empty 全局 min-width 132px；EmptyState 168px（移动端 140px）；图表空态 140px。
- **反馈**：一切提交类操作 loading → 成功/失败 ElMessage；产生工单类跳携带 `?focus=<id>` 并高亮目标行。
- **悬浮助手**：贴右边缘收起为圆钮，展开时内容区预留右 padding，不得遮挡卡片内容。
- **设备档案树**：节点高 34px；Hover 极淡蓝 `#f4f9ff`；选中 = 浅蓝渐变底 + 1px 淡蓝内描边 + 左侧 3px 主色渐变竖条（与侧栏菜单同款）；节点内不再重复「N号机组-」前缀。
- **骨架屏**：树/卡片首屏用同形骨架（行数 3–6、宽度 58%–86% 抖动、1.2s 扫光），禁止整页遮罩转圈；首帧加载中不得闪现「暂无数据」。
- **分级树加载**：默认懒加载（首屏只取根层，展开才请求下一层）；有搜索词 / 筛选条件 / 带 id 直入时回退全量，保证深层节点可被搜到。

## 8. 响应式

- ≥1440：满布局；1024：侧栏自动折叠为图标栏；≤800：工艺图/宽图横向滚动或降级为卡片列表，KPI 两列堆叠；≤768：侧栏抽屉化 + 遮罩。
- 断点改动只动布局容器，不动组件内部样式。

## 9. 动效

- 时长三档：`--motion-fast: 150ms` / `--motion-base: 220ms` / `--motion-slow: 360ms`；缓动 `--ease-standard: cubic-bezier(0.22,0.61,0.36,1)`，回弹仅用于按压、对勾、卡片入场。
- **整页更换**：路由 leave 150ms 上浮淡出 → enter 360ms `translateY(18px) + scale(.99)`；`<component :key="route.path">`，不用 `fullPath`。
- **统一卡片入场**：`.page.is-ready .dash-card` + 内联 `--i`，`animation-delay: calc(var(--i) * 50ms)`，keyframes `dash-card-in`（opacity 0→1、translateY(20px)→0，360ms forwards）。
- **异步插入内容同样入场**：数据到位后新增的测点卡、下属设备卡、翻页卡片靠同一个页面级 ready 选择器自动播放；`--i` 从主卡序号往后接续（主卡 0、区块 1、内部卡片 2 起）。
- **切换主体重播**：详情区包一层 `:key="selectedId"` 且 `display: contents` 的容器，换设备时整组卡片重放，不影响 flex 布局。
- **图表入场**：折线 clip 揭示 1000ms、柱状 800ms + 每根 45ms 错峰、环形 900ms；`setOption` 用双 `requestAnimationFrame` 延到空闲帧，否则首帧即终态。
- **入场动画与业务状态冲突**：`forwards` 会把 `opacity` 锁成 1，离线/禁用灰显必须用 `--end-opacity` 变量在 keyframes 里收尾，并在 `prefers-reduced-motion` 下还原。
- `prefers-reduced-motion: reduce`：关闭自动轮播/水波/数字滚动/入场，渲染静态终态。
- 验收：无头浏览器默认 990px 宽会命中窄屏断点，实测前先设目标视口（宽屏 ≥1600、窄屏 ≤1200 各一次）。

## 10. 反模式（禁止清单）

- 只靠颜色传达状态（无色点+文字）。
- 关键操作只有图标无文字且无 tooltip。
- 实时数据无更新时间、无 stale 态。
- 装饰图/渐变进入数据密集区影响对比度。
- 新页面自造密度、自造状态色、自造空态图（一律复用 token 与 EmptyState）。
- 表格窄屏溢出撑破布局（应横向滚动或卡片化）。
- 卡片撑满了、内容还堆在顶部留白；或用空块占位凑高度。
- 父/子节点底部结构不同却沿用同一套高度模板，导致子节点底部空出一块。
- 用 `forwards` 入场动画直接覆盖离线/禁用等业务透明度状态。

## 11. 页面范式

列表页 = 筛选区 +（可选）状态 KPI 卡 + 主表格 + 分页；详情 = 头部摘要卡 + Tab 分区；首页 = KPI 行 + 主状态区（工艺/地图）+ 待办列 + 趋势行。新页面从范式出发，只替换数据与业务区块。
