## 1. 系统简介

本系统面向泵站、水厂等生产现场，把 **设备台账、实时测点、告警、维修、巡检、维保、调度、供水与能耗、技术档案** 放在同一个平台里管理。

### 1.1 能帮您做什么

| 能力 | 说明 |
|------|------|
| 看得见 | 工作台 KPI、SCADA 实时值、告警列表 |
| 管得住 | 告警处理、维修工单审批—处理—验收 |
| 跟得上 | 巡检 / 维保计划与执行记录 |
| 调得动 | 生产调度指令审核与执行 |
| 算得清 | 供水计划/报表、电耗与电费 |
| 找得到 | 图纸、制度、标准、验收资料归档 |
| 问得清 | 智能助手：用自然语言查数据、查档案，确认后可创建工单 |

### 1.2 浏览器要求

- 建议使用 **Chrome、Edge、Firefox** 近两年版本  
- 推荐分辨率 **1366×768** 及以上  
- 请将系统地址加入收藏夹，由贵单位管理员提供正式访问地址  

> 界面外观可能因交付版本不同（深蓝政务 / 顶栏 SaaS / 浅色卡片 / 深色运维等）而略有差异，**菜单名称与操作逻辑一致**。

## 2. 登录与界面

### 2.1 登录

1. 在浏览器打开贵单位提供的系统地址。  
2. 输入 **用户名**、**密码**。  
3. 点击 **登录**。  

| 说明 | 内容 |
|------|------|
| 初始管理员（示例） | 由实施方交付时告知；常见为 `admin`（**首次登录后请立即修改密码**） |
| 账号被锁定 / 登录失败过多 | 稍候再试，或联系管理员解锁 / 重置 |
| 忘记密码 | 联系本单位系统管理员重置，勿共用他人账号 |

### 2.2 界面结构（通用）

无论界面风格如何，通常包含：

- **导航区**：左侧或顶部菜单，按权限显示可用模块  
- **标题区**：当前页面名称、当前登录人  
- **内容区**：列表、表单、图表  
- **退出**：在顶部或侧栏点击 **退出** 安全离开系统  

### 2.3 列表页通用操作

多数业务页支持：

| 操作 | 说明 |
|------|------|
| 查询 | 输入关键字、状态等条件后点「查询」 |
| 新增 / 编辑 | 打开表单，填写必填项后保存 |
| 删除 | 需有权限；删除前请确认业务影响 |
| 分页 | 底部分页器切换页码 |
| 详情 | 查看单条记录完整信息与操作日志（如有） |

## 3. 推荐使用角色

实际权限以管理员在「角色 / 菜单」中的配置为准。下表为推荐分工：

| 角色 | 主要使用模块 |
|------|----------------|
| 值班员 / 中控 | 工作台、实时告警、SCADA 监控、智能助手问数、简易工单 |
| 维修人员 | 工单处理、巡检任务、维保记录 |
| 班组长 / 主管 | 工单审批与验收、调度审核、巡检/维保计划、助手确认创建 |
| 调度员 | 调度统计、指令下达与任务跟踪 |
| 生产统计 | 供水计划/报表、耗能录入与电费 |
| 系统管理员 | 组织用户角色、设备与测点、告警规则、档案、助手与采集服务状态 |

同一账号登录后，**看不见的菜单表示当前角色无权限**，属正常现象。

## 4. 工作台

**菜单位置：** 工作台  

进入系统后的默认首页，用于快速掌握生产与待办概况。

### 4.1 页面内容

| 区域 | 作用 |
|------|------|
| KPI 卡片 | 待办告警、待处理工单、巡检/调度等关键数量（随统计周期变化） |
| 供水量趋势 | 近 7 / 14 / 30 天供水相关曲线（依赖测点与数据） |
| 耗能分析 | 能耗概况图表 |
| 待办列表 | 维修工单、告警等待办，可点击跳转到对应业务页 |
| SCADA 状态 | 显示采集/仿真是否运行中 |
| 快捷入口 | 部分待办可一键跳转告警、工单、调度等页面 |

### 4.2 建议用法

1. 每班接班后先打开 **工作台**。  
2. 查看待办数量，优先处理高等级告警与待派/待验工单。  
3. 点击待办行或「全部」进入明细页面办理。  
4. 可用顶部 **近 7 天 / 14 天 / 30 天** 切换统计窗口，点 **刷新** 更新数据。  
5. 需要快速问数时，可用 **智能助手**（见第 14 章），不必逐页翻菜单。

## 5. 设备与 SCADA

### 5.1 设备管理

**菜单位置：** 设备管理（含设备分类、设备台账、厂商、维保单位等，以实际菜单为准）

**建议初始化顺序：**

1. 维护 **设备分类**（如主机组、闸门、电气、仪表等）  
2. 维护 **生产厂家 / 维保单位**  
3. 在 **设备台账** 中录入设备名称、编码、位置、所属分类等  
4. 如需联动告警与实时数据，为设备绑定 **SCADA 测点 / 变量 ID**（按实施约定填写，如 `700`、`PLC1.Flow`）

> 设备档案是后续告警、工单、巡检、维保的基础，请保证编码唯一、名称清晰。

### 5.2 SCADA 采集（值班可见部分）

**菜单位置：** SCADA采集 → 测点配置 / 实时监控  

| 页面 | 用途 |
|------|------|
| 测点配置 | 登记测点名称、节点（NodeId）、数值类型、单位、是否启用；仿真参数（仅仿真环境） |
| 实时监控 | 查看各测点最新值与时间戳；启停采集/仿真、必要时注入（权限依角色） |

**日常使用：**

1. 打开 **实时监控**，确认数值在刷新、时间戳在变化。  
2. 若全部无数据：联系管理员检查 **采集服务**（仿真或 OPC-UA Gateway）是否启动、测点是否启用。  
3. 联调或演练时，授权人员可对指定测点 **注入数值**，用于验证告警规则——**生产环境勿随意注入**。

### 5.3 采集方式说明（给管理员 / 实施）

系统支持两种常见部署（对值班界面操作相同）：

| 方式 | 说明 |
|------|------|
| **内置仿真** | 主程序内模拟测点波动，适合演示与开发 |
| **独立 SCADA Gateway** | 独立服务采集并推送数据到业务系统；可接 **Mock 仿真** 或 **真 OPC-UA 现场** |

接现场时，测点 **节点 ID** 需与 PLC/OPC 地址一致；切换与联调清单见实施文档 `OPC_UA.md`。  
历史数据可能按策略保留一段时间（如 90 天），超期由采集服务清理，不影响业务办理。

## 6. 告警管理

**菜单位置：** 告警管理  

### 6.1 告警类型

维护告警分类（如温度告警、故障位告警等），供规则归类展示。

### 6.2 告警规则（管理员 / 技术人员）

配置「什么条件下产生告警」，常见要素包括：

- 关联测点  
- 比较方式（高于 / 低于 / 等于等）  
- 阈值  
- 告警等级（一类 / 二类 / 三类）  
- 关联设备（可选）  
- 是否启用  

规则启用后，系统按采集值自动评估；满足条件即生成实时告警。

### 6.3 实时告警（值班重点）

**菜单位置：** 告警管理 → 实时告警  

可按关键字、等级筛选。常见操作：

| 操作 | 何时用 | 说明 |
|------|--------|------|
| **一键处理** | 告警待处理 | 接单/进入处理中状态 |
| **申请维修** | 需现场检修 | 生成维修工单，进入工单流程 |
| **维修完成** | 处理完毕待验 | 进入待验收 |
| **忽略** | 误报或可忽略 | 记录后关闭类处理（谨慎使用） |
| **验收通过 / 驳回** | 待验收 | 通过则关闭；驳回可继续处理 |
| **详情** | 任意时刻 | 查看触发值、时间、关联工单等 |

页面会显示与服务端的实时连接状态（如 WS 已连接），便于确认告警能否及时推送。

### 6.4 历史告警

查询已结束或归档的告警，用于复盘、考核与报表。

### 6.5 告警等级建议

| 等级 | 建议响应 |
|------|----------|
| 一类 | 立即处理，必要时报值班长 / 申请抢修 |
| 二类 | 当班优先处理 |
| 三类 | 纳入计划或观察，按规定时限闭环 |

## 7. 维修工单（核心闭环）

**菜单位置：** 维修工单  

工单可来自 **告警申请维修**，也可按单位制度人工登记（以页面功能为准）。

### 7.1 工单状态说明

| 状态 | 含义 | 主要责任人 |
|------|------|------------|
| 待派单 | 已申请，等待审批派工 | 审批人 / 班组长 |
| 维修中 | 已派给维修人员处理中 | 维修工 |
| 待验收 | 维修人已提交处理结果 | 验收人 / 管理员 |
| 已归档 | 验收通过，流程结束 | — |
| 已驳回 | 审批未通过 | 申请人视情况重新发起 |

### 7.2 分角色操作入口

| 菜单 | 适用 | 操作 |
|------|------|------|
| **工单审批** | 主管 / 班组长 | 通过并派工、或驳回并填写意见 |
| **工单处理** | 维修人员 | 查看任务、填写处理反馈、提交完成 |
| **工单验收** | 管理员 / 授权人员 | 验收通过或驳回（驳回后回维修中） |
| **全部工单** | 有权限人员 | 全量查询、统计各状态数量 |

### 7.3 标准闭环（建议全员熟悉）

```text
发现告警 / 故障
    → 实时告警：一键处理 → 申请维修
    → 工单审批：通过并指定维修人
    → 工单处理：现场维修并填写反馈 → 提交
    → 工单验收：通过 → 工单归档，关联告警关闭
                 驳回 → 返回维修中继续处理
```

**注意：**

- 验收通过后，关联告警一般同步关闭，请确认现场确已恢复。  
- 审批驳回后请查看意见，勿重复盲派。  
- 工单详情中可查看操作日志，便于追溯。

## 8. 设备巡检

**菜单位置：** 设备巡检  

| 页面 | 说明 |
|------|------|
| **巡检计划** | 制定巡检周期、对象、内容；到点或手动 **派发任务** |
| **巡检任务** | 执行人领取/完成任务，登记正常/异常项 |
| **巡检记录** | 历史结果查询；支持计划外补录（权限允许时） |

### 建议流程

1. 管理员或班组长维护 **巡检计划**。  
2. 按计划派发 **巡检任务**。  
3. 巡检人现场检查后在系统中提交结果；异常项及时转告警或维修。  
4. 管理人员在 **巡检记录** 中抽查完成率与异常项。

## 9. 设备维保

**菜单位置：** 设备维保（维保计划 / 维保记录 / 台账汇总）  

| 页面 | 说明 |
|------|------|
| **维保计划** | 按设备/周期制定保养计划并派发 |
| **维保记录** | 登记实际保养内容、时间、执行人 |

## 13. 档案管理

**菜单位置：** 档案管理  

用于存放图纸、制度、标准、验收资料等生产技术文件。

### 常用操作

| 操作 | 说明 |
|------|------|
| 上传 | 选择分类、填写名称与说明，选择文件上传 |
| 检索 / 筛选 | 按关键字、分类、是否收藏筛选 |
| 下载 | 下载原文件（系统会累计下载次数） |
| 收藏 | 将常用文件加入个人收藏，便于查找 |
| 删除 | 一般仅管理员；删除前确认无替代版本 |

### 使用规范建议

- 单文件大小受系统限制（常见上限 **50MB**，以贵单位配置为准）。  
- 文件命名建议：`设备或系统-文件类型-版本-日期`。  
- 分类使用：图纸 / 制度 / 标准 / 验收 / 其他。  
- 重要纸质扫描件建议上传 PDF，并在说明中写明纸质存档位置。

## 14. 智能助手

**菜单位置：** 智能助手 → 对话  

用自然语言与系统交互（需单位已部署 **本地大模型** 与助手服务）。界面可能随主题略有不同，功能一致。

### 14.1 能做什么

| 能力 | 示例 |
|------|------|
| 查业务数据 | 「当前有多少待处理告警？」「有哪些维修中工单？」「测点 700 现在多少？」 |
| 查工作台摘要 | 「工作台待办有哪些？」 |
| 查设备 / 调度 / 巡检 | 「列出运行中的设备」「有哪些待执行调度」 |
| 查档案知识 | 「制度里轴承温度巡检怎么规定？」「有哪些管理制度文档？」 |
| 受控创建 | 「帮我建一条维修工单…」→ **确认卡片** → 点确认后才写入 |

更完整的示例见 [附录 C](#附录-c智能助手示例问句)。

### 14.2 界面说明

| 区域 | 作用 |
|------|------|
| 左侧会话列表 | 切换历史对话、新建会话 |
| 顶部状态 | 本地模型 / 助手服务是否就绪 |
| 对话区 | 提问与回答；工具调用会显示「已查询 · xxx」标签 |
| 确认卡片 | 写操作挂起后出现：摘要、参数、**确认执行 / 取消** |
| 输入框 | 输入问题；Enter 发送，Shift+Enter 换行 |

### 14.3 使用步骤

1. 登录后打开 **智能助手**。  
2. 顶部状态应为「就绪」；若显示不可用，联系管理员。  
3. 直接输入问题，或点击空态示例问题。  
4. 回复可能 **逐步显示**（流式）；查询业务数据时可能先出现「正在查询…」。  
5. 若出现 **写操作确认卡片**：  
   - **确认执行**：用当前账号权限写入系统（如生成工单号）；  
   - **取消**：不写库。  
6. 左侧可打开历史会话继续聊（服务重启后历史可能清空，以现场部署为准）。

### 14.4 创建工单 / 调度时注意

- 创建 **维修工单** 通常需要 **设备 ID**；可先问「查一下设备列表」，再让助手按设备建单。  
- 创建 **调度指令** 需要 **执行人用户 ID** 与 **期望完成时间**；信息不全时请补充后再确认。  
- 未点「确认执行」前，系统中 **不会出现** 新工单/新指令。  
- 助手 **不能代替** 审批、派单、验收等需人工把关的环节。

### 14.5 注意与边界

- 助手 **不能绕过权限**：你菜单里看不到的数据，助手也查不到。  
- **不要** 把密码、密钥、个人隐私发给助手。  
- 对话过频可能被限流，稍候再试。  
- 扫描件 / CAD 图纸往往 **抽不出正文**，只能按文件名、说明检索；制度类请尽量上传可检索的 PDF/Word/TXT。  
- 助手回答业务数字时，应以工具查询结果为准；若与页面不一致，以业务页面与现场为准并反馈管理员。

## 15. 系统管理（管理员）

**菜单位置：** 系统管理  

面向系统管理员，日常运维人员一般无需进入。

| 功能 | 用途 |
|------|------|
| 部门 / 班组 | 组织架构 |
| 位置 / 机组 | 现场空间与机组划分 |
| 用户管理 | 开户、停用、重置密码、分配角色 |
| 角色管理 | 配置角色可访问的菜单权限 |
| 菜单管理 | 菜单结构维护（一般由实施方初始化） |

### 管理员上线检查清单

1. 修改默认管理员密码  
2. 建立部门、班组、岗位用户  
3. 按岗位分配角色，核对菜单可见性（含「智能助手」）  
4. 录入设备与测点，配置关键告警规则  
5. 试跑：告警 → 工单 → 验收 全流程  
6. 上传必要制度与图纸到档案库（供助手检索）  
7. （若启用）确认 SCADA Gateway / OPC-UA 采集与主站联通  
8. （若启用）确认本地大模型与 AI 服务就绪，试问数、试确认建单  
9. 按单位制度完成培训与 UAT 勾选（见 `UAT.md`）

## 16. 典型日常流程

### 16.1 值班接班（约 5 分钟）

1. 登录 → 打开 **工作台**  
2. 看 KPI 与待办：告警、工单、调度  
3. 打开 **实时告警**、**SCADA 实时监控** 扫一眼异常  
4. （可选）问智能助手：「当前待处理告警和待办工单有多少？」  
5. 交接班记事写入本单位规定载体（系统内工单/调度备注亦可）

### 16.2 告警到修复

见 [第 7.3 节标准闭环](#73-标准闭环建议全员熟悉)。

也可由助手查询告警后，人工在 **实时告警 / 工单** 页面完成处理与验收（推荐关键操作仍走业务菜单，便于留痕）。

### 16.3 计划巡检日

1. 班组长在 **巡检计划** 派发当日任务  
2. 巡检人完成 **巡检任务** 并提交  
3. 异常转维修或上报  
4. 主管抽查 **巡检记录**

### 16.4 月末统计

1. 核对 **供水计划** 与 **供水报表**  
2. 完成 **耗能录入**，核对 **电价**  
3. 查看 **电费统计**、**水电耗对比**  
4. 导出或截图存档（按单位报表制度）

### 16.5 用助手起草工单（可选）

1. 打开智能助手，说明设备与故障现象  
2. 若需要，先让助手查设备列表拿到设备  
3. 出现确认卡片后核对参数，点 **确认执行**  
4. 到 **维修工单** 列表确认工单已生成，再按审批/处理流程办理

## 17. 常见问题

### 登录相关

**Q：提示密码错误？**  
A：确认大小写与输入法；连续失败可能触发限流，等待数分钟后再试或联系管理员。

**Q：登录后菜单很少？**  
A：账号角色权限不足，联系管理员分配角色，不是系统故障。

### 数据相关

**Q：SCADA 没有实时数据？**  
A：检查测点是否启用；采集/仿真或 Gateway 是否运行；接现场时检查 OPC 连接。联系管理员查看系统健康状态。

**Q：告警不产生？**  
A：确认规则已启用、阈值与测点绑定正确；可在测试环境用「注入测点值」验证规则。

**Q：供水/能耗图表是空的？**  
A：缺少测点历史或手工录入数据；先保证采集与录入，再查报表时间范围。

### 业务相关

**Q：工单无法验收？**  
A：状态须为「待验收」；通常仅管理员或授权角色可验收。

**Q：档案上传失败？**  
A：检查文件大小与格式是否允许；网络是否中断；是否有上传权限（一般仅管理员可上传）。

**Q：页面显示异常或按钮点不动？**  
A：强制刷新浏览器（Ctrl+F5）；更换浏览器；仍不行请记录操作步骤与时间联系支持。

### 智能助手相关

**Q：智能助手显示不可用？**  
A：本地模型或 AI 服务未启动，联系管理员检查 Ollama / 助手服务与主站配置。

**Q：助手答的数字和页面不一致？**  
A：刷新业务页面再问一次；仍不一致以业务页面与现场为准，并反馈管理员排查。

**Q：确认执行工单后提示无权限？**  
A：当前账号没有创建工单权限，请换有权限账号或联系管理员。

**Q：问了制度内容，助手说档案库没有？**  
A：确认档案已上传且可被检索（优先 PDF/Word/TXT 正文）；扫描件可能需补说明文字。管理员可重建档案索引。

**Q：对话提示过于频繁？**  
A：触发限流，稍候再试。

**Q：历史会话不见了？**  
A：助手会话默认保存在服务内存中，服务重启后可能清空；重要结论请落到工单/记录中。
