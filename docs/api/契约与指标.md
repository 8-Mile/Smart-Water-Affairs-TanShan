# API、指标与模型网关契约

共享 Schema、角色权限、状态枚举及 DTO：`packages/contracts/src/index.ts`。计算：`packages/domain/src/index.ts`。场景权威种子：`apps/api/src/seed.ts`。本期只支持固定演示日与预置雨次，非现场实时数据。

## 身份和范围

`POST /api/demo/session {role}` 返回 token 和隔离演示用户。业务接口使用 `Authorization: Bearer <token>`。会话有效期8小时，进程重启后重新登录。角色与 north/south 范围由服务端决定，不接受请求自报权限。

## 查询与修改

- `GET /api/health`：服务和存储就绪。
- `GET /api/me`：用户、范围与动作权限。
- `GET /api/snapshot`：首页、六工艺、设备、告警、工单、水量、雨次、健康及模板统一快照。
- `GET /api/subsystems[?scenarioId=...]`、`GET /api/subsystems/:id`：工艺查询。
- `GET /api/assets/:id`：设备、时序、健康依据和关联记录。
- `POST /api/metrics/query`：入参 DashboardSchema，返回 widgetId→授权数据行；不接受SQL或任意表达式。
- `GET /api/reports`：用水、设备、告警、工单四类报表，受功能开关限制。
- `POST /api/alarms/:id/transition`：`{action: acknowledge|recover|close,note,epoch}`。
- `POST /api/workorders`：`{assetId,eventId?,title,description,epoch}`，创建草稿。
- `POST /api/workorders/:id/transition`：`{action: submit|assign|start|review|close|cancel,note,epoch,version}`。
- `POST /api/decision/four-pre/run`：`{rainMm,areaM2,coefficient,initial,capacity,outflow,hours}`，返回基线与处理能力提高50%的对比结果。
- `POST /api/admin/scenarios`：`{scenarioId,reset,keepDashboards}`，仅管理员/主持人。
- `POST /api/admin/features`：`{feature: reports|health,enabled}`，仅管理员。
- `GET /api/admin/audit`：最近300条审计视图；场景复位不删除审计。
- `GET /api/dashboards`：本人看板。
- `POST /api/dashboards`：`{layout,id?,version?}`，更新必须匹配版本。
- `POST /api/dashboards/:id/restore`：`{target,version}`，旧布局另存为新版本，不删除历史。
- `GET/POST /api/preferences/:key`：本人设备表格列、顺序、筛选和排序。
- `GET /api/ai/tasks`：本人任务和工具步骤。
- `POST /api/ai/tasks`：`{prompt,layout?,assetId?}`。
- `POST /api/ai/tasks/:id/approve`：`{dashboardId?,version?}`，同一事务检查权限、场景epoch和任务状态；重复确认拒绝。

## 指标定义

- 总用水量：授权区域当日终端消耗合计；不叠加收集、处理和回用内部流转。
- 再生水利用比例：演示假设终端消耗30%为回用水，标记SIM，不代表实测成果。
- 账本：流入−消耗=储量变化；本演示损失与统计误差设0。
- 单位水电耗：kWh/m³；缺测点、零分母返回null。基线北区两泵分别0.25和0.20。
- 健康：100−故障数×15−min(20,floor(运行小时/1000)×5)，最低0。与电耗独立，不代表安全鉴定。
- 雨量入流：雨深mm/1000×面积m²×径流系数，均匀分配每小时。
- 库容：出流不超过可用水量，超容量水记为overflow，85%容量为模拟预警阈值。

设计参考容量不参与模拟容量自动累加；未知用null，界面显示未提供/不可计算。

## 模型网关

AI_GATEWAY_URL接收POST JSON：`{prompt,layout,context:{scenarioId,areas},contract,allowedDatasets,allowedComponents}`；可选Bearer API Key。返回`{layout:DashboardLayout}`，12秒超时。额外脚本、未知字段、无权区域、删除/移动安全锁定组件均拒绝。

未配置网关时执行标明来源的离线模板/规则，不宣称实时模型理解。网关失败保留旧版；设置AI_FORCE_OFFLINE=1重启可恢复离线演示。真实模型环境未提供，仅验收了本地替身的成功与失败契约。

池体保障：`POST /api/decision/supply/run {storage,reserve,demand}`，不占用保留水量，需求必须大于0。`GET /api/metrics/definitions`返回注册指标字典。图表查询每条数据携带场景、SIM/CALC、指标码、单位、质量和计算依据。
