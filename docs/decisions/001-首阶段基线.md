# 首阶段工程基线

采用需求的 Vue / TypeScript / Pinia / Naive UI / UnoCSS / ECharts 与 NestJS 方向。当前环境 Node 22；实际依赖兼容后锁版本，不直接沿用文档未核验的版本结论。

本次交付：共享工艺/角色/场景契约、Nest 查询 API、隔离演示会话、Vue 导航及六工艺数据概览。模拟数据是纯函数确定性样本，每次请求显式指定场景；尚无持久化修改或生产控制接口。

角色默认动作：管理者只读；值班员确认告警和创建工单；运维办理；访客只读。工单派发、审核和关闭的独立授权后续补充。当前只有查询端点，写入权限仅声明，不能视为工单流程已经实现。

首页四项指标尚未建立计算口径，显示未提供，不用六工艺局部数据拼凑总量。公共模板发布留在 P1。模拟登录接口仅用于本地 DEMO，服务绑定回环地址，不能作为生产认证。

后续：数据库迁移与持久化种子、组织/工艺数据范围、审计、完整统一指标服务，然后打通中压供水纵向闭环。
