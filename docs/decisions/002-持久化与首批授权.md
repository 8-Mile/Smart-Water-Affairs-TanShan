# 本地 DEMO 持久化与首批授权

本机无 Docker。选用 @electric-sql/pglite 作为嵌入式 PostgreSQL，数据保存在 API 的 .data/postgres，支持事务和 JSONB。官方资料：https://pglite.dev/docs/ 。Docker Compose 保留用于后续服务端部署；当前不是网络 PostgreSQL 适配器。

本期采用单进程、单演示实例。数据库 migrations 记录版本；demo_state 存储版本化 DEMO 聚合，所有修改通过事务锁定行提交。聚合中包括四场景的设备、告警、工单、个人看板版本、AI 任务、配置和审计。生产版应拆分索引表和正式身份认证。本地进程只监听回环地址。

场景切换保留目标场景已有业务记录；复位只恢复指定模拟场景。每次切换/复位递增 epoch，取消待确认任务。个人看板默认保留，不改设计资料。该语义采用 V1.2 第20.5节，不采用早期无差别清空方案。

演示管理者显式拥有工单派发与验收权限；值班员可确认、发起及提交本人草稿；运维仅能办理北区派给本人的任务；管理员仅配置和审计；主持人仅场景管理。只读用户仅北区数据。所有写入与对象范围由后端检查。

AI_GATEWAY_URL 是可选的提供方中立 JSON 网关。无网关时仅执行明确标识的规则/模板解析。模型路径与业务核心分离；模型返回必须通过共享 Schema 与权限检查，不执行任意源码。没有提供真实模型环境，交付验收须注明真实模型未实测。
