## 明确限制

1. AI目前以明确标识的规则/模板完成首批演示。网关适配和异常保护已实现、经本地替身测试；真实模型质量及真实服务连通性未实测。
2. 数据库为单进程嵌入式PostgreSQL，非已部署的网络PostgreSQL；生产账号认证、组织维护、真实测点接入未交付。
3. 工艺关系为业务示意，容量和设备为模拟/待核，不接真实PLC、不进行硬件改造。
4. 公共岗位模板审批发布、复杂自定义业务规则、三水源多目标求解、移动深度巡检、语音与ESP32/BLE仍为后续范围。
5. 任意日期范围、完整趋势缩放/异常标记及全部通用组件的深度配置仍需后续完善；本次时间轴为固定演示日和最近两/三次雨次。
6. 构建仍有第三方Zod注释及部分分块大于500kB的提示，不影响构建与本地演示；前端页面已按需加载，图表库按组件引入。
