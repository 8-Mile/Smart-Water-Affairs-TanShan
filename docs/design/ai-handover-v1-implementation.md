# 唐港智慧水务 · AI多步骤运行检查与交接班报告 V1

## 定位

复用**现有AI助手**完成一条真实可执行的多模块业务链：
**一句话发起任务 → 值守巡查（条件允许时执行）→ 查询值守事件 → 查询生产告警 → 查询未完工单 → P-002健康规则核验 → 形成交班报告预览 → 值班员确认存草稿 → 管理者演示审核**。

本阶段不是“真实大模型自主Agent”或“无人值守已投入运营”。任务识别为规则解析；各业务步骤直接调用现有数据和确定性工具，记录工具调用和成功/受阻状态。仅在页面操作时执行单次巡查，并非后台常驻调度。报告是生成时刻的MOCK快照，不代表当日24小时监控，也不代表全部六套工艺均正常。

## 入口

1. 在本机打开 `http://localhost:5173/overview`；
2. 顶部点击「问 AI」；
3. 输入「帮我完成今天的运行检查，整理异常情况，生成交班报告」，或点击「一键交班报告」示例；
4. 点击「解析指令」，自动运行当前授权角色可执行的一次中压供水巡查；
5. 在AI抽屉中看本轮巡查ID、值守事件、活动生产告警、未完工单、设备健康检查、受阻步骤、报告预览和数据覆盖范围；
6. 点击「确认保存交班报告草稿」，由本地权限服务校验角色后写入共用的报表草稿存储；
7. 点击「在常用报表查看草稿」，打开 `/data/reports?handoverId=...`；
8. 管理者或系统管理员输入审核意见后可点击「确认演示审核归档」；之后可导出Markdown格式的MOCK报告；
9. 只读工程运维角色可运行只读数据汇总，但无权替值班员执行本次巡查或保存交班草稿。

## 核心专业逻辑

**1. 巡查真实性**：有 `unattended:execute` 权限才执行 `unattended.runPatrol()` 并生成真实演示巡查ID；无权限或失败不能写“本轮完成巡查”，而应记录受阻或任务失败。页面没有打开时不会自动巡查。本期仅P-002中压供水有专业巡查规则。

**2. 事件统一引用**：读取已有 `useUnattendedStore` 活动事件及 `useDemoStore` 的生产告警、当前未关闭工单。不重复创建事件或工单；在报告中保留原事件ID、告警ID及工单ID。

**3. 健康规则复用**：对现有P-002设备调用 `scorePumpHealth()`，读取有效（quality=valid）的振动、温度和电流参考数据，原有演示阈值和缺失项校验保持不变。缺测时健康分为null，不擅自把缺数视为零风险。

**4. 报告范围**：输出当前“值守事件、生产告警、待办工单、演示巡查、P-002健康、遗留风险”；注明模拟种子数据参考时刻与任务生成时刻不同。没有事件不等于全港正常，其他五套工艺仍需现场巡查。

**5. 人工确认**：生成预览不会自动保存；保存只生成 `pending_review` 草稿，存于 `tanggang-handover-reports-v1`，重复确认通过ID幂等处理。管理角色输入意见后写入 `reviewed` 状态、角色及审核时间；仅是浏览器演示归档，不是正式有身份签章的生产记录。

**6. 安全边界**：任何步骤均不启停设备、修改阀门或设置阈值；也不自动创建、派发维修工单。AI任务记录复用现有 `recordAgentRun`；每次交班任务拥有唯一任务ID，预览和确认操作均有步骤标记。

## 验收条件

- 无异常：本轮巡查及报告能生成，但“覆盖1/6”和“数据仅为MOCK”仍必须显示；
- 有异常：报告引用值守事件UT编号、原始活动告警及未完工单；
- 无权限：禁止替他人执行巡查、禁止未授权草稿保存或报告审核；
- 数据缺失：健康评分和巡查步骤显示受阻，不能虚构结果；
- 草稿保存：只有显式确认才写入，不重复创建；刷新仍能在常用报表查看；
- 管理审核：必须填写审核意见，记录角色、时间、状态，不得重复审核；
- 取消任务：不生成报告草稿，也不产生新的生产操作；
- 原有功能：设备管理、组态、智能值守、雨前调蓄、多水源优化、AI分析、告警工单与常用报表均保留。

## 工程与试点边界

- **当前可验证**：本地多步骤编排、规则化计算/查询、报告草稿、角色约束、演示审核、界面跳转、回归测试。
- **现场试点前需要**：六套工艺的测点与巡查规则清单、班组岗位与工单责任分工、班次时间、真实数据时间戳和质量管理、值班日志模板、历史事件与实际履历、具名身份和服务端审批流程。
- **尚未完成**：真正大模型的任意任务规划、任务暂停后跨设备继续、单步骤自动重试/补偿、服务端24小时调度、正式签章归档、智能体自学习、真实PLC和视频数据连接。
- **下一轮建议**：补充多任务流程模板（例如报警分析+报告+任务草稿）、用户确认后的步骤再执行、服务端任务执行持久化；随后优先开展泵组能效匹配与运行优化。

此阶段将AI编排作为跨模块入口，但不新增独立的“AI交班系统”业务台账。
