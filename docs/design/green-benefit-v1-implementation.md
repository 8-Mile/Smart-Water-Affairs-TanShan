## 核心问题

不能只报“回用了多少雨水和中水”或“节约了多少自来水”：需先确认港区是否实际有对应回用需求、来源是否符合用途水质、存在可到达的供水路径、库存是否可用且不重复计量，才能在同等用水需求与可比的全自来水供应基准下算费用差。

因此方案分别显示“少购自来水量”“基础综合单价费用差”“增加独立核算成本后得到的条件净费用差”，且严禁把前两个概念直接称为实际节约。

## 条件费用口径与公式

全部按相同需求Q、同一时段、同样已配置的水质/连通/供水能力比较。

每种来源 i 的增量单位成本（条件模拟）：

effectivePrice_i = existingUnitCost_i + treatment_i + transfer_i + residual_i + extraKwhPerM3_i × tariff

注意：existingUnitCost_i 源于原多水源模型，已被定义为包含一部分处理和能耗的综合运行成本。新增 treatment / transfer / residual / extraKwh 只能是明确假设不在该综合单价之内的增量，严禁重复计费。

比较前必须重算原多水源路径/优先级分配，以获得当前配置各来源的水量 V_i。

原单价条件下的“基础费用差”：Q × tapExistingPrice − ∑(V_i × existingPrice_i)。

条件当前费用：∑(V_i × effectivePrice_i) + fixedReuseCost。
- fixedReuseCost 是只在雨水或中水被使用时计入的本时段额外固定运行维护费；
- 不含工程资本投入、折旧、融资、税费、应急供水可靠性价格、法律责任和碳资产；
- 不计算污水/雨水所谓“避免处置收益”，除非现场有真实合同、库存守恒和流程证据（本期不纳入）。

条件全自来水基准：Q × effectiveTapPrice，前提是全自来水路径满足同一用水对象的全部需求，否则为不可比。

条件净费用差 = 条件全自来水基准费用 − 条件当前费用。
- 正值：情景净节约；负值：情景净增支；零值：持平。
- 若当前方案有未满足供水、全自来水基准不可行、成本边界未确认，净费用差与“少购自来水量”的比较结论均按具体限制降级或隐藏。
- 少购自来水量仅是同等用水需求下的购水替代量，不是整个港区总取用水节约量或生产节水量。

## 页面及流程

1. 右上（或菜单）进入绿色运营效益核算页。
2. 默认看四项关键指标：同周期供水需求、少购自来水量、全自来水可比费用、条件净费用差。
3. 下方看成本分解、水源分配条和未满足水量。
4. 用“正常成本 / 中水水质受限 / 供水能力不足 / 成本导致净增支”验证方案风险。
5. 专业人员展开成本参数，修改源库存、原单价、新增处理/药剂、输配、残渣、电耗、固定成本以及用水需求；必须点击“重新计算”使参数生效。
6. 支持显式导入最近保存的三水源建议；重新计算并保留原草稿ID作来源，不复制旧优化结果。
7. 有 water:proposal 原权限的岗位可以保存待工程复核的本地核算草稿；保存前复算并校验比较条件和未改动的结果。只读角色无保存权限。
8. 未执行对PLC的操作、真实设备调度或后台数据录入。

## 工程可信度、未实现项及试点前置条件

本期全部是离线MOCK/人工输入，**不是实际经营ROI模型**。

进入现场试点前必须核实：
- 回用设施、泵站、输配管线和各用水终端的P&ID、设备接线、阀门及水质适用要求；
- 分表计量水量、水质、进出水与蓄水水量平衡、独立水源库存及同一结算周期；
- 合同自来水价、再生水供水合同、化验与药剂、药渣或污泥处置、泵站分表电耗和电费、增量固定运维成本；
- 成本科目是否已在来源综合单价内、是否与其他模块重叠、财务认可的基准方案；
- 资本投入/折旧/折现、处理产物处置环境合规与耗材成本、可靠性与极端工况的备用要求；
- 正式版本的服务端数据和可审计的人工审核流程。

不能根据模拟回用量计算港口真实减碳，也不能将已验收工单、设备健康分视为能耗实测记录。
