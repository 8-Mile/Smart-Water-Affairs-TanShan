# 09 · 遗留风险与六工艺专业页面开发计划

## 1. 遗留风险

| 风险 | 影响 | 现状/缓解 |
|---|---|---|
| 设计设备与 5175 资产未建立 `assetId` 映射 | 设备点击只能只读展示，不能跳转统一详情 | 追溯链已预留 `assetId/metricId`；页面已明确“未接入” |
| 49 条设计设备全部未定位、无实时值 | KPI 呈现 50/50/50，易被误解为缺失 | 页面文案注明“设计设备类别/未定位/未接入实时”；不使用假数据 |
| V2.7/V2.8 存在候选断点与未审批管段 | 部分管线显示为“待核”，不能宣称已连通 | 保持原始审计标注；断点面板可逐项核对 |
| 场景首屏 5–26s | 首屏体验偏慢 | 与源页同量级；后续资源压缩、分批加载、启动骨架 |
| `@types/three` 版本落后 | 类型提示可能遗漏新 API | 运行与类型检查均通过；后续独立升级 |
| 六系统正式名称待工程资料确认 | “生活污水处理”可能需改为“提升/外送” | 以 `systems-v2.5.json` 为准，改名需同步数据与文档 |
| 新路由未绑定权限码 | 所有登录用户可见总览 | 仅登录校验；专业页面再细化权限 |
| 5175 数据库曾修复 | 约 47 行历史采样丢失 | 已记录在 00；不影响业务档案 |

## 2. 六工艺专业业务页面开发计划

前置条件：完成设计设备 ↔ 5175 资产 ↔ SCADA 测点映射，并确认正式工艺名称。

### 阶段 A：主数据与权限（先行）
1. 建立 `facilityId → assetId`、`assetId → metricId` 映射表（以工程设备位号为准）。
2. 新增权限码：`port:overview`、`port:fog`、`port:middle`、`port:mineral`、`port:rain`、`port:pool`、`port:domestic`。
3. 统一数据性质字段，禁止页面自造状态。

### 阶段 B：六个专业页面（逐个交付，复用同一套骨架）
| 页面 | 路由建议 | 核心内容 |
|---|---|---|
| 射雾器除尘 | `/port/fog` | 射雾器台账、分区覆盖、联动状态（只读） |
| 中压供水 | `/port/middle` | 泵组、压力/流量趋势、管段拓扑 |
| 含矿污水处理 | `/port/mineral` | 处理工艺链、池体液位、出水指标 |
| 雨水收集 | `/port/rain` | 集水池、泵组、降雨与液位联动 |
| 水池供水 | `/port/pool` | 南/北池、供水泵组、水量平衡 |
| 生活污水处理 | `/port/domestic` | 提升/外送流程、设备状态 |

每页统一结构：顶部系统导航 + 左栏 KPI/图例 + 中央 Three.js 聚焦 + 右栏设备/告警/趋势；复用 5175 表格、抽屉、图表与动效。

### 阶段 C：验收
1. 每页与总览同视口截图对比，确认管网、标签、设备一致。
2. 设备点击走 5175 统一详情抽屉，避免重复建档。
3. 实时值必须标注来源与时间戳；无来源时显示 REF/SIM，不显示“实测”。
4. 生产远控、PLC 联锁仍不在范围，需单独立项与安全评审。
