**本次树位 CSV 的口径**：重放现有 `harborRelief.ts` 的 treeSites 生成过程，对每个树心求距最近可绘制道路中心折线段的平面距离，以当前显示路面半宽 0.66 为阈值。西侧窗口 -57<x<-39、-45<z<35，东侧窗口 x>22。源树索引是本次诊断编号，不能当 CAD 资产 ID。该表覆盖这组生成树，不含其他独立 CAD 冠层、树冠净空或车道扩宽后的冲突。修复后对最终全部来源与实际路面多边形重新计算。
