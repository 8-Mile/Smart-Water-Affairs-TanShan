## A　修旋转闪动，先处理深度精度再处理重叠面

实页慢转时相机确实改变方向，本次采样中 canvas 未被替换、WebGL 上下文丢失为 0。V2 的逐帧渲染和停泊船修复继续保留。随后将镜头依次置于 A → 极小水平偏转 B（0.000075 弧度）→ A；同一视口、镜头中心、角度、场景、远裁面和阈值，只有 near 改动。两组同姿态 A→A 复拍，陆域 ROI 的明显变化均为 0%。统计阈值为 RGB 任一通道差大于 12。

| ROI，屏幕坐标按左闭右开 | near 0.1 的 A→B | near 8 的 A→B |
| --- | --- | --- |
| 陆域 x55–1625，y278–703 | 5.946% | 1.764% |
| 北区 x200–1230，y280–328 | 18.964% | 4.701% |
| 南区 x220–1460，y606–694 | 5.679% | 0.686% |

该试验说明默认相机的深度精度是重要因素。转动本身也会产生正常像素变化，剩余比例不能全部算作闪烁。参见 5190-rotation-test.jpg。当前场景实拍约 347 次 draw call、149 万三角形，单独的 FPS 数值不能验收表面闪点。

1. 从项目根目录执行 git apply --check 指向本包 5190-depth-precision.patch，确认当时源码仍匹配，再由 TRAE 应用。补丁只调透视相机近裁面，依轨道距离与相机高度平滑过渡。用同一算法在测试页检查：距离 323.6 时 near=8，150 时约 2.16，70 和 25 时为 0.1，返回总览恢复 8。本轮未覆盖所有设备近景与真实触控，正式合入前补测。
2. 保持同样相机路径，分层隐藏道路覆面、煤场场坪、透明贴片、原始辅助线、细管、阴影与标牌，定位残余。优先去共面重叠、修重叠几何和细线的屏幕尺度。重点看北侧厂坪、西洗车台、堆间路和南廊道。分别记录建筑表面跳色、正常锯齿、标签换位、整屏黑闪与帧耗，不能用一份 FPS 报告替代。
3. 在用户平常的屏幕缩放、显示 DPR 和设备上，左右慢转各一次、快速来回、拖动后松手、缩到最近、系统聚焦、复位。交付稳定性视频及同机位前后帧差。若仍有整屏闪，单独保留可复现手势与录屏。

## B　先做西侧道路—洗车台—排水沟样板

以 FA905、D58A4、FB499 和北横路 CF248 为核对段。先截一张 CAD 道路与沟渠叠图，再截当前彩色和道路单材质图。在真实相交处让道路有独立面、路肩和连续的路口。FB499 沿线剖开堆底板或在网格构造阶段扣除工作走廊；验证地面、煤堆坡脚、机座和水管在旋转后仍能分清。南横路先调材质，东侧园区用建筑入口校核支路。把 41 条结果更新到 CSV，分别登记“原有且可读、已修覆盖、正常遮挡、原始资料待核”。

做一段贴着真实道路的排水沟，表达开口截面、走向和过路格栅。以实际 handle 追溯，明沟、盖板、泄水通道各有合适的表现方式。两条沟边不重复造两条沟。现场未核的去向在原位置收口。端头、标线和格栅从三种角度看都应稳定。

## C　用已制作的 Blender 洗车台完成代表区

本包 wash-station-l1.blend、wash-station-l1.glb、build_wash_station.py 是本轮制作的可编辑样件。1568 三角形、8 个材质批次，显示包络约 8.6×12.4，已在 5190 隔离页以原洗车台表现位置替换旧几何。新旧机位对照见 5190-wash-pilot.jpg。样件表现浅色双坡棚、透空支架、作业台、条形格栅、入口截水沟与两侧冲洗管。尺寸、车道和管件均为 L1 示意。
 
接入时复用 TG-CAD-13/FAE1D 拾取和原详情；保留场地原点，平面 footprint 与真实安装轴线分别记录。移除样件所替代的旧棚板和重复场坪，纳入原资产加载、阴影与资源释放逻辑。在同一机位检查入口投影中粉色管线和黄色支腿的重叠，区分穿模和纯遮挡。只在有 CAD 依据时改变实际走向，按展示图层/高度或构件尺寸处理其余重叠。首轮交一幅样板区三联图，连续执行剩余工作，无需等用户中途审批。

## D　样板通过后向北、东、南扩展

北侧先完成“主路—厂前场坪—澄清池—泵房—集水池”的空间层次。四个圆池能看见水，北二南五分别数得清楚，链斗冲洗池单独可点。对照规格书盘点除尘水池、格栅井与闸门等室外构筑物；逐项标记可直接落图、区级示意、待定位。沿用已完成的泵房 GLB。
东侧以人工湖、办公、维修车间及智慧中心组成第二个样板。用厂前路与入口区分楼栋；把树放在能衬托湖岸的侧后方，保留相机、资料和业务锚点。需要时在 Blender 精修车间大跨屋盖及大门、智慧中心横向体量，检查运行时另附的屋顶几何。
南侧让池带、管架、岸墙和水面依次可辨。在有依据的码头室外设备中选一类做可复用母版；安装点资料不足时作为区级示意。既有船体继续用，核对 52 船裁切与岸机/船关系，避免让泊位抢占全场水务画面。

## E　统一三维美术，再复验设计稿

先在西侧样板校准一套光和材质。路是中性沥青，场坪是较亮混凝土，金属管有窄高光和暗侧，窗带与屋面有阴影，水面按海、湖、池分别校准。处理堆面重复、远景球形树冠与过密林缘，再推广到整场。检查实际 Three.js 颜色管理、环境贴图、雾、粗糙度和曝光；围绕同一张实拍做单变量对照，保留兼容的现有灯光。除业务确需的流带外避免全场发光。增强中压主管远景可见度，沿用 139320 的演示业务语义。
 
相同 1672×941 画幅下，目前 B1417 岸线高度约在 y=712，设计图水陆边界约 y=819。设计图侧重视觉构图，CAD 固定实际场地关系。真实坐标优先时记录这约 107 像素差异；用材质、体量、光影和遮挡缩小观感差距。若须变更全场主机位以达成另一种构图，先留候选截图、说明哪些设施会被裁，包括人工湖和 52 船。保留可回退的正式机位。

## F　按 V2 分工完成整屏验收

1672×941 默认首屏和关标签全景为主验收图。补 1920×1080、2560×1080、390×844、设备日常 DPR，并完成手机画布底部留白的定位、细管/相邻池/湖/洗车台/维修车间“实体与标签相同 ID”的回归。交付同路由 30–60 秒静止、慢转、缩放、开关管流和复位实录，选最有代表性的西、北、东各一个同尺度前后近景，连同实际帧间隔、构建和测试结果。资料未提供的数量或轮廓单列，不能写为通过。

每一阶段记录实际改动、证据及下个未完成项。模型导出、数据清单对上、近景截图、构建通过分别验收；最终以默认相机下道路走得通、设施读得清、转动稳定为准。
