- 独立支路各自从 0 起算，不跨交叉、近邻或未知接口自动连成一条路线；未接实时数据，流动为演示状态，方向按折线绘制方向，不作水力方向证据。
- 演示主管：`$管综-中压除尘` 源 Handle `139320`，6 点折线、约 98.9 单位、含三处转弯。默认视图只演示该图层；选中「中压除尘/中压供水」后突出该线路并让关注图层流动；停流时 `aFlowOn=0`，管身保持可见。
- 拾取改为面顶点 `aPick` 反查原折线段，点击仍回到单个 CAD 源 Handle，不把多段拼成已核实管路。详情中对演示段明确标注「演示数据 / 关联设施候选为同系统文字锚点，实际接管未核」。
