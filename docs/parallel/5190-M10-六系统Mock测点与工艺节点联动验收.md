# 唐港5190 · M10 六系统Mock测点与专业工艺节点联动

## 1. 产品执行边界

继续按照原定唐港七大菜单、六系统SCADA、供水保障、主动智能监护、研判处置与A2UI的业务主线，先交付完整、可操作的Mock演示产品。现场数据采集、硬件选型、协议和业主资料核实，待用户在后续阶段明确提出时再统一研究，不是当前软件开发前置条件。

六系统所有示例状态和测点数据均为确定性Mock假设，与真实设备、现场仪表、历史采集、环保达标、PLC控制、正式告警/工单严格隔离。CAD设施名称及测点字段仅来自已上传资料形成的映射清单。

## 2. 本批功能

1. 新增前端纯函数 processMock.ts，针对现有六系统设计设施生成稳定可复算的Mock读数，按泵、池、阀、仪表、控制柜、管道和处理设施的类型生成不同状态与参数；不凭空添加设备或测点ID。
2. 直接增强原PortProcessSchematic.vue节点：专业图标、Mock状态、设备侧一项示例参数，关注与异常采用既有低饱和度状态色；不重新设计一套AI风格UI。
3. 原PortProcessView.vue右侧设备资料保留，新增模拟运行状态、完整模拟测点字段、数值单位和来源标记。既有设备详情与工程关联权限逻辑不变。
4. 未启动全局情景时展示“Mock基线”示例；启动后沿用唯一Pinia全局情景，允许查看中压泵异常、生产供水高峰与强降雨的可视化关注节点，退出情景恢复Mock基线。
5. 泵故障仅将EQ-P-MID标为SIM异常，配套EQ-P-METER标为SIM关注，两者压力与流量统一取自同一情景输入。其他泵组不被推断故障；监护引擎逻辑没有复制或改写。
6. 高峰只对中压泵组与除尘水池进行“SIM关注”视觉提示；强降雨只对相关设计排水区域进行“SIM关注”，不将单池水量复制成南北多个集水池的真实测值。
7. 库存水量及消防保留量按m³显示，瞬时流量按m³/h，压力MPa、液位m；未知语义显示“未配置Mock值”，缺测明确显示“缺测（SIM）”，不把空值变成0。
8. 390像素及窄屏点击节点，自动定位右侧详情；不改变成熟字体、导航或组件体系，也不修改TRAE负责的Three.js和CAD源文件。
