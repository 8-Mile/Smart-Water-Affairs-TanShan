# 唐港5190 M12：六系统业务定向与节点定位验收

## 产品原则

维持原定唐港七大模块、六套专业工艺及既有供水保障、主动监护、情景处置、SIM运行复盘的业务主线。现阶段先完成可操作Mock演示，不将现场传感器、PLC采集、通信协议和业主补资料作为前置。待产品整体完善后按用户要求单独研究数据与硬件需要。继续复用已成熟的浅色卡片、字体、Element Plus；不新增一级菜单或通用组态编辑器。

所有状态与数值均为设计资料参照和确定性SIM/Mock示例，不能替代真实水质检测、泵站设备诊断、污水排放许可、管网水力校核与生产调度。

## 本期解决的问题

### 六套专业业务不再误跳到中压泵监护

1. 中压供水对应供水保障分析、供水SIM处置研判。仅在明确的EQ-P-MID或EQ-P-METER设计设施上提供中压泵SIM监护入口。
2. 水池供水对应供水保障与供水SIM处置研判，但统一模拟水池的库存量不等于除尘水池或实体池的实测储量。
3. 雨水收集对应雨水调蓄模拟。强降雨时只展示单个独立演示集水单元的模拟雨量、库容与溢流，不表示南北实际池站的水力连通。
4. 射雾器除尘、含矿污水处理、生活污水提升与外送当前尚没有独立专业定量模型。只提供本专业的CAD设施、Mock测点和SIM人工核查，不再冒称中压泵监护或供水方案就是本系统分析。
5. 雨水调蓄页移除不相干的中压泵监护跳转，改为跳到已有CAD设计设施EQ-Y-DRAIN（排水沟及闸门）进一步核查。普通SIM若未设置降雨则不编造降雨风险结果。

### 当前工艺工作区的快速定位

原工艺设施分区头部增加轻量化快捷条，按同一全局SIM轮次标记：
- 定位SIM关注/异常：在当前系统的设计设施中循环定位现有规则标记的节点，并更新原URL设计设施ID与右侧详情。
- 定位本轮已核查：按本轮浏览器SIM人工核查记录循环定位、显式标记已留痕设施。换情景或退出即清空，不能当成现场巡检已完成。
- 无SIM、无关注或者无已核查节点时相应操作禁用；无需添加一堆新卡片。
- 顶部简述明确是SIM快速定位或Mock基线，避免误认实时采样。

### 设备数据隔离修正

先前只要启动全局SIM，全部设计设备都会显示“SIM情景”，包括根本未被情景影响的其他设施。本轮改成只有真正引用情景输入或被该情景明确标为异常/关注的节点才显示SIM情景；其他设施保持确定性Mock基线和原本的示例读数。同一设施跨工艺仍共享相同Mock参数，不重复造设备表与测点ID。
