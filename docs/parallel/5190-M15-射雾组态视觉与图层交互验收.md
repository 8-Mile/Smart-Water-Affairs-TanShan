# 唐港5190 M15：射雾组态视觉与图层交互验收

## 业务目标

用户要求使用此前设计的专业子工艺图，点击设备在右侧展示现有业务卡，并保留5144之前的二维组态编辑能力。M14已恢复射雾编辑、服务端草稿/发布/版本，M15沿用旧版图元与成熟浅色组件，优先修复工艺视觉主次和操作问题。

## 本轮修改

1. 重新布局为水源参考、加压与控制、室内射雾三个视觉分区；图元为原可编辑PNG资产而非不可编辑的底图贴片。三分区仅为阅读辅助，不能用于推断已建成水力网络。
2. 放大泵、水池、阀门、室内射雾器和控制柜，调整标签与压力表位置。保留6个模板图元（3绑定、3未绑定）及4条设计示意连接，不制造额外设备。
3. 水路从设备图元边缘进入或离开，用蓝色虚线；控制信号使用灰色虚线，避开阀门标签。每条连接标记illustrative，不代表实际输水关系或控制连锁。
4. Mock状态及CAD建议字段显示在设备旁独立信息卡。标签位置在画布内约束；专业射雾低压工况下泵组出口压力0.32 MPa、室内射雾压力0.29 MPa，点击设备与右侧Mock卡使用相同规则数据。
5. 新增“水路示意、控制信号、Mock数据”三种图层显示开关。切换仅影响当前可见性，不修改草稿或发布版本。
6. 修复编辑器的假修改问题：此前只点击选择图元就会触发撤销快照及未保存修改标识；现在只有实际拖动改变位置才创建单条撤销快照。
7. 390px及窄屏保留图元可读尺寸，在工艺图内部横向滚动，并提示可以左右滑动，整体页面不横向溢出。
8. 保留旧编辑器的图元库、绑定、增删、拖动、撤销重做、草稿、发布和历史恢复。其他五套业务工艺未改动。
