# 唐港 5190 · M18 CAD端点核查与五套工艺证据分层

## 目的

M16/M17 完成了五套工艺逻辑图和图上交互，但工艺逻辑线不等于真实 CAD 管段连通。M18 不改动工程主线，不增设新业务菜单，只在五套工艺页面内增设折叠式 V2.8 CAD 核查入口，让评审和开发人员能够追溯图层端点、CAD Handle 和疑点位置。

射雾除尘由于 V2.5 系统映射中无对应专业管线图层，不显示此入口，不以其他系统的图层数据冒充射雾线。

## 页面交互

- 在五系统工艺图下方折叠展示 `CAD 管线端点核查`；默认不展开，不增加页面顶部卡片，不覆盖编辑器。
- 点击“展开端点与疑点”时才加载大体量静态核查 JSON，避免影响平时打开工艺图的性能。
- 展开后按当前系统关联CAD图层展示端点/待核/疑点/high优先统计；多图层可以切换。
- 提供“待核端点”“疑点”“全部候选端点”筛选、CAD Handle/相邻Handle/坐标检索及分页。
- 完整 Handle 精确命中时优先展示同一源Handle，不被其他记录的“最近候选Handle”混入。
- 每条记录展示源 Handle、端点状态、候选/隐藏相邻 Handle、场景 XZ 和原始CAD XY。均是来源台账证据，不推断真实控制设备。
- 仅用于设计核验；不触发工单、告警、远程PLC或生产控制。

## 工程后续（不得把下述证据缺失标记为通过）

1. 原始DWG、图层和管段高程分离核验；对照Handle复查端点、三通、阀门、真实接口。
2. 建立“CAD源Handle ↔ 设施台账 ↔ 组态节点”**人工确认**映射表后，才能在具体组态管线处显示核查状态；目前不可把同图层Handle自动映射到某台泵。
3. 回访设计方确认南北集水池的真实流向、除尘水池两座单体关系、生态调蓄的条件约束，以及生活污水处理路径。
4. 若接到新增/修订 CAD，先更新原 CSV 和版本号，再运行生成脚本及测试，拒绝在没有审计资料的情况下伪造“已核实”状态。
