# 唐港5190｜M7：唯一运行标识与资料核验留痕

## 目标
修复M6仅使用“情景+轮次序号”关联决策、复核和SIM报告的跨浏览器刷新误关联风险。把现场资料、泵组参数、终端负荷、管网、水质等待核实事项纳入原有研判页，不增加一级菜单和AI风格页面。

本期全部数据仍为开发Mock的SIM演示假设，不是唐港实测、正式审核或真实调度依据。

## 入口
模拟处置研判：http://localhost:5190/port/operations/decision
SIM运行复盘：http://localhost:5190/port/analysis/reports
大机供水保障：http://localhost:5190/port/water/supply
主动智能监护：http://localhost:5190/port/operations/monitor
AI智能助手：http://localhost:5190/ai/chat

## 完成的业务能力
1. 每轮统一情景开始时生成UUID v4标识；切换、刷新或者新轮次不复用上一轮标识。前端AI、监护、复盘、决策共享相同SIM上下文。
2. 以运行唯一标识关联决策/复核/报告，防止刷新后同名场景“第1轮”互相串联。新决策已有唯一标识后，复核必须给出不同的新标识，同一情景且轮次递增、起始时间变化。历史M6无唯一标识数据可读取；只有安全匹配时才关联旧基线，不靠单纯轮次补造旧复核。
3. 研判页“待核实资料”按固定工程核对项、SIM情景检查点、所选方案模型阻断项生成；所有条目仅表示待检查，不代表已有文件或现场证据。
4. 点击核验项，记录“尚未核对/资料待提供/资料核对中”、人工核对意见与可选资料线索。后端保存追加式事件，不覆盖历史记录，独立tg_mock_ai_evidence_note表按用户/决策隔离，复用AI审计。
5. 系统禁止将核验状态直接改为“已核实”，不会依靠文字备注或来源名称宣称工程数据已验证；来源线索仅代表人工输入。
6. 生成SIM复盘时冻结关联研判的核验状态、条目及意见。报告展示核验清单和生成当时进度，并可跳转原研判记录。
7. 新增明确的运行ID核验、条目白名单、用户权限、非法状态防护；所有新接口仅在本机开发Mock启用，不允许真实泵阀、PLC、正式设备、告警、工单或SCADA写入。
