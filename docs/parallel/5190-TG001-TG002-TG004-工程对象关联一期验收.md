# 5190｜TG-001、TG-002、TG-004 工程对象关联一期验收

## 交付边界

本轮是**可用的后端数据关系基础与六工艺页面可编辑入口**，不是已经完成的现场CAD-设备-点表全量映射，也不是生产SCADA联通验收。

- TG-001：后端六系统唯一字典；与前端menu中的6个固定systemId一致。
- TG-002：新增对象关联数据库、REST API、角色写权限、关联快照审计；六工艺页面只在后端存在关系时显示设备详情和已绑定测点个数。
- TG-004：SCADA测点统一数据质量包络，模拟/缺测/过期/离线/错误质量均不被当作真实运行值；开放带测点质量的关联查询。

## 数据库变更

后端在服务启动时通过既有ensure_schema()->metadata.create_all自动创建4个独立表：
- tg_object_link：object_id、facility_id、system_id、cad_handle、source_ref、verified、审核人、时间、创建及修改人。
- tg_link_asset：将同一映射关系关联多台真实设备ID（外键到eq_equipment）。
- tg_link_metric：将同一映射关系关联多个真实测点ID（外键到scada_points）。
- tg_object_link_revision：创建、修改、解除、恢复操作的before/after历史快照。

本轮没有向水务数据表、SCADA历史表或告警工单表写入演示值；也没有自动造种子工程关系。

## 实际API

已注册、需有效JWT：
- GET /api/v1/tanggang/systems：六系统字典。
- GET /api/v1/tanggang/object-links：支持system_id、object_id、facility_id、asset_id、metric_id过滤、分页、include_latest。
- GET /api/v1/tanggang/object-links/{id}：读取单条。
- GET /api/v1/tanggang/object-links/{id}/revisions：查看操作版本。
- POST /api/v1/tanggang/object-links：创建新关联（需要现有eq:update权限）。
- PUT /api/v1/tanggang/object-links/{id}：更新设备/测点和工程依据，固定对象/设施/系统身份（eq:update）。
- DELETE /api/v1/tanggang/object-links/{id}：软删除，只解除关联，不删除真实设备或SCADA测点（eq:update）。

约束：system_id必须是六系统之一；设备和点位ID必须存在且未删除；已有指定设备的测点必须同步包含所属设备；同一object_id+facility_id+system_id唯一；标记verified需要工程依据source_ref。verified只表示人工审核对象对应关系，绝不表示CAD管道连通/方向/水力条件已验证。

## 数据模式与质量

带include_latest的读接口返回measurements：metric_id、asset_id、value、unit、data_mode、quality、observed_at、source_ref、calculation_version。

- SCADA mode=mock：data_mode=SIM。
- 其他运行模式：保守data_mode=UNKNOWN，直到具体测点来源独立获得现场核实，不直接判断MEASURED。
- 缺测值null；数字0保留为合法数值，不等于缺测。
- 可输出GOOD/STALE/BAD/MISSING/OFFLINE；错误时间或无效数值不应显示成正常实时数据。
- 工程映射本身data_mode=REF，hydraulic_topology_verified固定为false。本字段只表示尚未建立独立的水力拓扑审核，不可通过对象绑定顺便置true。

## 前端入口

进入5190“运行监测”→任意六工艺详情页：
1. 若工程设施绑定了业务对象，可见正式设备名称并点击跳转设备详情，另显示关联测点个数。
2. 有eq:update权限的用户将鼠标移到设备行，可点击“关联”或已有记录的“编辑”。
3. 对话框需要输入**真实**三维objectId，选择现有设备台账及可选测点；可补充CAD Handle和工程依据并人工勾选审核。
4. 保存成功后从后端重新查询；取消、校验失败时不写入；解除关联不删除业务设备。
5. 无证据的设计设备继续保持未定位、未映射状态，不能自动制造cad:XX对象ID。

**关键差距：现有CAD设计设备清单共49项，sourceCadHandle有值为0项。** 因此目前不自动生成任何正式对象关联；需等待TRAE提供场景objectId清单和CAD/现场勘察核验表，方能开始逐条绑定。设计设施分类不等于实际安装数量。
