# 5190｜TG-003 数据口径与资料对账开发验收

## 0. 用户确认的基础事实（项目强制约束）

唐港51·52号泊位智慧水务5190 **目前没有经过现场核实的真实运行数据**。已经掌握的工艺、设备与CAD参考来自用户上传材料；各业务页面用于展示的流量、压力、用水量、能耗、降雨与告警情景等数字均视为**演示假设或依据资料推导**。旧5175遗留SCADA模拟器、设备台账和时间序列虽能正常写读，也不因此成为唐港现场真实数据。

所有后续开发、AI推理和方案汇报遵守：

1. **资料参考（DOCUMENT_REFERENCE）**：必须保留所引用的用户材料名称、图号或页码；设计参数不是实时运行值。
2. **资料推导（ASSUMPTION）**：必须注明计算方法、推导依据与假设边界；不得说成业主确认。
3. **演示假设（DEMO_VALUE）**：用于软件功能、联动和测试，不能写为唐港历史实测。
4. **尚未核对（UNVERIFIED）**：缺少来源时不要填0、不要自动推断水路或资产ID。
5. **不提供 MEASURED/FIELD_VERIFIED 录入选项**：现场核对尚未完成，任何时间戳或接口响应都不能自动升级真实状态。
6. **资料审核不代表现场验收**：工程对象的资料核对标识与物理连通、水质、PLC和设备安全状态完全分离。

## 1. 已落地功能

### 后端

- 数据阶段：GET /api/v1/tanggang/data-context（需已登录）。返回DOCUMENT_BASED_DEMO、USER_UPLOADED_MATERIALS、现场确认=false、现场PLC连接=false、可视作实测点数=0。
- 既有测点资料清单：GET /api/v1/tanggang/point-audit（需已登录）。支持测点检索、所属系统、资料类别、分页；返回既有SCADA注册表记录，但默认全是待核对，绝不自动判为唐港现场点表。
- 记录资料与假设：PUT /api/v1/tanggang/point-reviews/{point_id}（需要既有scada:point:update权限）。仅允许UNVERIFIED、DOCUMENT_REFERENCE、ASSUMPTION、DEMO_VALUE；必填资料或推导说明；修改只写入tg_point_review和tg_point_review_revision，不改动SCADA测点、采样值、设备或工单。
- 审计追溯：GET /api/v1/tanggang/point-reviews/{point_id}/revisions。记录核对人、前后资料信息及时间。
- 数据模型：新建tg_point_review、tg_point_review_revision两表；后端现有ensure_schema机制会在启动时create_all，不覆盖旧表。

### 前端

- 新页面：/port/data/provenance，位于七大模块“设备运维”之下的“资料与测点核对”；页面权限复用scada:monitor，编辑另需scada:point:update。
- 可按工艺、类别与Tag/NodeId筛选；可核对来源、资料编号、假设；有系统分类但无现场实测认证选项。
- 从用户资料中的49项设计设施和建议采集字段生成CSV对账模板；来源值为现有design catalog，CAD Handle、三维objectId和SCADA点位ID均留空待核。下载文件不能视为采集点表。
- 首页和业务页面顶部仅显示一个必要的中性提示“资料演示”，没有增加多余说明卡片；API访问失败时依然保守显示演示状态。
- 六套工艺子菜单仍严格为fog、middle、mineral、rain、pool、domestic六项；不增加独立总览、不改变既有首页。
- 六工艺的关联进度数据显示“资料关联”与“现场未核实”，不是“数据已接入”。既有绑定弹窗改为“资料对象关系核对（非现场核验）”。

### 数据示例和边界

- 当前设计设备类别/条目数量：49项，sourceDoc字段均引用“第四分册”，sourceCadHandle有值0项。注意此49是现有本地资料结构中的条目数，不等于现场安装台数。
- 第六系统命名差异：源文件systems-v2.5.json中名称“生活污水处理”；5190业务菜单及产品方案为“生活污水提升与外送”。系统ID继续固定domestic，具体工艺与资料版本待核实，不擅自改变现场工艺或虚构处理设施。
- 既有scada_points全部只是待核对的本地注册表对象，未经逐项资料核对不能当唐港测点；将其标为DOCUMENT_REFERENCE只能表明引用了某份用户资料，**不意味着该测点确实位于唐港现场**。
- 旧5175生成的数值会继续服务于独立原业务演示；本次没有批量抹掉旧数据，也没有将旧值直接移为唐港实测。
