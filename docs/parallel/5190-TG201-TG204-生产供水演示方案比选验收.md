# 5190 TG-201～204：生产供水SIM方案比选交付记录

## 数据与工程边界

当前唐港项目没有现场核验的测点、泵曲线、储量曲线、作业需水量或管网通断结果。数字均为用户上传资料背景下的演示假设；模块不执行真实控制，不创建生产告警，不写SCADA历史或工单。

## 本轮软件功能

- supplyPlans.ts：四方案纯函数对比：维持现状、低优先级作业顺延50%、保障假设水池安全线、假设增加35m³/h备用能力；各方案均记录输入、演示约束、期末理论储量和未核实前提。
- store.ts：唯一的SIM输入快照；全局控制台预校验后原子更新、跨业务共享、停止即清空。
- ScenarioConsole.vue：六项假设参数仅由统一情景入口调整，支持恢复预置。
- SupplyPlanComparison.vue：比选表、约束详情、带演示声明及模型版本的JSON结果导出。
- PortSupplyAssuranceView.vue：嵌入现有供水业务页，不增加一级菜单与独立总览。

特别约束：负的期末储量只是恒定流量下的未截断数学外推，不能解释为水池实际负水量；判断为库存不满足。顺延需求不等于实际节水；增加设备能力不等于现场有备用泵。模型内未越线也不构成工程可行性结论。

## 当前测试结果

- 新增方案计算单测7项通过；
- Vue TypeScript检查通过；
- 浏览器Mock接口下1600x900与390x844均显示四方案，统一参数编辑更新同一轮结果，无页面横向溢出及生产API写入；
- 缺现场工程/水质/管网联锁条件，当前只验收SIM软件功能。
