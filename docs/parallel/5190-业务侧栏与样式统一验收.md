# 5190唐港业务侧栏与样式统一：本轮验收

## 目标
业务页面左侧菜单与港区首页顶部菜单共用七大模块，保留5175成熟组件、折叠和过渡动效，修复因两个菜单来源不同造成的结构不一致。

## 实施
1. 配置唯一来源：frontend/src/modules/tanggang/business/menu.ts。
2. frontend/src/composables/useAppMenus.ts 将唐港配置投影成现有Element Plus菜单数据结构。后端用户菜单及登录权限继续参与原业务叶子菜单的可见性判断。
3. frontend/src/modules/tanggang/home/components/DashboardHeader.vue 同用useAppMenus，顶部与左侧不再重复实现过滤逻辑。
4. frontend/src/themes/layouts/EmberLayout.vue 保留原有高亮滑块、菜单展开、折叠、响应式布局、页面淡入动效；修复父级菜单index与子页面path重复问题，自动展开当前路由的父菜单。
5. 新建业务页面使用原平台art-card、page-fill、主题色、统一圆角和柔和入场动效；支持减少动画系统偏好。
6. 六系统ID：fog/middle/mineral/rain/pool/domestic；第六系统页面按生活污水提升与外送管理口径。
7. 避免相同叶子路由在多个左侧业务菜单重复出现；跨模块操作由业务页上的链接继续承载。

## 验证
- 本轮vue-tsc类型检查通过；顶部/侧栏/新业务组件开发服务编译均为HTTP 200。
- Vitest：七一级模块、叶子路由唯一性与解析、六系统ID与路由归属测试3项通过。
- Chrome隔离浏览器：1600×900布局无水平溢出，导航展开和射雾器专业页跳转均正常。
- 浏览器隔离测试禁用了GPU，AI浮动助手Three.js产生WebGL初始化错误；属于测试环境限制，不构成本轮业务菜单缺陷证据。
