# 5190 业务页面与三维引擎并行开发边界

本目录为5190项目开发分工协调；不得修改5175和5188原始项目。

## 角色分工
- ChatGPT业务线：frontend/src/modules/tanggang/business/**、frontend/src/modules/tanggang/home/components/DashboardHeader.vue（顶部七菜单）、frontend/src/router/index.ts（新增业务路由）、未来专业页面、API/权限与业务模型。
- TRAE三维线：frontend/src/modules/tanggang/scene/**、frontend/public/tanggang/models/**及与三维渲染直接相关CAD资产。必要时可编辑 frontend/src/modules/tanggang/home/TanggangHome.vue 中场景交互绑定，但不能覆盖业务导航文件、入口路由、菜单配置，不得修改 DashboardHeader.vue 与 business/**。
- 共用需事前协商：frontend/src/modules/tanggang/mapping/tanggangCatalog.ts、首页总体样式 home/styles/tanggang-home.css、后端数据接口与跨模块事件契约。

## 数据和路由契约
- 六系统ID固定为 fog、middle、mineral、rain、pool、domestic。
- 专业总览 /port/monitor；详情 /port/process/:systemId。
- 三维首页 /dashboard 和 /port/overview。
- 推荐首页引擎读取URL query参数 system，支持回到三维并自动聚焦；该联动由TRAE负责。
- 对象关联 CAD Handle → objectId → facilityId → assetId → metricId → systemId。
- 未接入的设备不显示虚假的实时水位、流量、压力与在线指标。
- 六套系统不是六个孤岛，仅高亮有工程依据的管网；第六套暂按生活污水提升与外送管理，不虚构处理线。
- 任何Three.js操作不得直接绕过PLC安全边界。

## TRAE交付
1. 六系统聚焦：右侧卡片、首页交互、场景联动、URL可恢复。
2. 聚焦关联设施、已核实管线和浮动标签；修复新增渲染缺陷。
3. 设备点击暴露统一object/facility ID。
4. 支持整体水循环视角；待核实水路不得当作真实连通。
5. 提供1920和4K截图、性能和对象映射核查结果。
6. 不修改业务团队持有的文件。

新业务页目前优先展示工程参考数据与已存在的运管平台功能；实时接口、算法和统一事件引擎待后续建设。
后台动态菜单与存量角色权限仍按5175运行，后续需要单独的幂等迁移方案，不能直接覆盖生产权限。
