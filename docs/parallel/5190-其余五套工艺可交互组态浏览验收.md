# 唐港5190 · 五套工艺区域化图元浏览与右侧业务卡联动

## 交付定位

承接既有射雾M14/M15编辑样板，修正另外五套工艺仍为大面积平铺设备卡片的问题。页面继续使用项目已有导航、设计CAD目录、Mock运行数据、业务右侧详情和原生样式token，未增设新菜单或编辑器。

此轮完成的是**统一工艺图浏览层**，不是五套完整可发布的组态编辑器；不能宣称原设计图已1:1复原。

## 已实现

- 使用CAD设施所在分区与原始顺序自动排布SVG图元；自动换行、区域标题、示意底网格；设备符号复用射雾图元库PNG，未覆盖的类型使用中性图元。
- 每个图元展示已登记设施编号、名称、Mock状态及一项Mock参考读数；随SIM情景、关注/异常和节点核查状态响应。
- 点击图元调用已存在的选中设备动作，右侧展示设备、Mock测点、资料、关联关系、SIM人工核查/复盘等原业务卡。路由通过 `?facility=` 保留选中目标。
- 窄屏图内可滚动，不制造整页横向溢出；键盘Enter/空格选中图元；保留关注和已核查快速定位功能。
- 未确认的示意点位只依据CAD区域分组，所有图元在画布中的x/y为阅读排版；**不自动创建水力连接、现场控制或真实告警**。
- 射雾M15既有视觉、拖动、保存、发布和历史能力保留，不以新的浏览图替换。

测试结果：`vue-tsc --noEmit` **0错误**；对应布局与CAD现有分区两套测试 **7/7**；Puppeteer模拟授权、隔离后端生产写入，五工艺路由每项均核实图元数量、首次图元选择、`?facility` 与右侧Mock详情同步；390px宽页面整体无溢出而图内可横向滚动。

本机无GPU的headless Chrome对全局Three.js渲染器提示过6次`Error creating WebGL context`，不是工艺页面业务异常。排除此类已定位环境报错后，页面脚本无其他捕获异常。

同一时间进行的M15回归：前端13文件/80测试通过，后端66测试通过。两组回归包含本次布局测试。
