# 5190菜单精简与5174业务亮点复用评审

## 本轮5190已修改
- 保留 /dashboard 唯一全局三维综合总览。
- 删除运行监测、水资源管理、运行处置、设备运维、分析中心五组无功能性“总览”二级菜单与两份共享总览Vue组件。
- 旧 port/monitor、port/water、port/operations、port/assets、port/analysis 仅保留兼容重定向，直达专业功能。
- 一级菜单跳至对应有实际功能的首个授权子页面；六系统路由和ID继续为 /port/process/:systemId。
- 开发环境登录框预填 leader / 6位本地演示密码，不自动提交；生产构建不预填，账号本身未重置、密码未核验。

## 5174复用判定原则
继续以5190为唯一产品基线，5174只提供业务设计、模型计算参考、交互流程和测试用例。绝不直接复制5174的旧路由、样式、全局Store或localStorage业务存储；所有正式记录应复用5190现有后端数据库、设备权限与事件工单。

## P0 优先落地（三项）
1. **生产供水保障 / 关键用水终端**：参考5174 MachineSupplyView、WaterBalanceView、portChain；在5190水资源管理下建立“大机供水保障”和“供需平衡”专业页。接大机副水箱液位、卸船作业状态、水池储量、泵站压力流量；源到用途关系必须核实；先用参数情景显式标SIM。
2. **主动智能监护 + 事件与维修闭环**：参考5174 v46-intelligent-monitoring-pilot、v47-event-correlation-consolidation、unattended/eventHub；复用5190告警中心与维修工单的原记录ID，不复制事件状态机。先实现多点联判证据页和规则审核，再逐步增加储量提前预测。无效测点不等于0，停机不直接作为运行故障。
3. **六工艺 / 设备 / 水路统一关联**：参考5174 v37资产工作区和工程核查；在5190建立三维对象、设施、资产、SCADA测点及工单统一ID。场景由TRAE处理，业务侧先做对账清单和设备详情下钻。无CAD/接口依据不标真连通。

## P1 建议迁入，但按新后端重新实现
4. **A2UI分析工作台 → 我的看板 → 预览 → 发布 → 已发布看板**：参考5174 v55-a2ui-preview-publication、WorkspaceView、DashboardsView、PublishedDashboardsView、dashboardPublication.ts。原版本为浏览器本地发布记录和目标标签，并没有真的发布到综合驾驶舱。5190应建设受控组件白名单/查询契约、服务端版本快照、岗位权限、发布范围、撤回与审计；必须能回答“发布到哪里、谁可以看到”。
5. **雨前调蓄方案比选**：参考5174 dispatch.ts和water-dispatch-v1。保留逐小时水量守恒、基准/腾库/回用三方案、排放与回用约束、方案不可行拦截；先作为可追溯试算，接真实降雨预报、库容V-H和雨水收集设施后才能用于生产建议。
6. **三水源经济优化与绿色效益**：参考multisource.ts、greenBenefit.ts。校核用水用途、水质、管线连通、时段能力、库存与来源成本；严格防止重复计量及重复计费；节约金额只有在同等需求和可比基准下成立。
7. **泵组健康与能效**：参考 health.ts、pumpEnergy.ts；可先保留规则型健康评分与试算。功率、电耗、扬程、厂家Q-H/效率曲线及工况数据不足时，不能宣传实测效率或节电收益。
8. **AI自然语言业务操作**：参考ai-command.ts、waterAiWorkflow.ts和agentRuntime.ts。先做受限、可审计的查询与草稿生成；“新增设备、调整表格、保存看板”需工具白名单、字段核验、预览确认、后端事务与回滚。5174原项目局部为规则解析/模拟Agent，不能当已具备生产级多Agent自治。

## P2 暂缓（先保留方向）
- 真实跨系统自动调度泵阀：必须核对PLC授权、联锁、安全及厂商接口，不因具备AI入口就自动执行。
- 无人值守视觉识别、语音ASR与ESP32：可试点，但受摄像头角度、标定、采集硬件与本地推理条件制约，不挤占供水和事件闭环的首批工期。
- 高级PHM剩余寿命、端到端多Agent自主执行：需要足够历史故障样本、专业评估、可靠运维边界。

## 最终业务菜单不需要独立总览
运行监测：六工艺详情。
水资源管理：供水统计/大机供水保障/供需平衡/雨前调蓄/多水源比选。
运行处置：告警中心/主动监护/运行处置（复用单一事件源）。
设备运维：设备台账/巡检/维保/档案/设备健康（可后续新增）。
分析中心：AI工作台/我的看板/已发布看板/报表与知识诊断。
系统管理：权限/点表/告警规则/日志/SCADA接入。
所有新模块正式加入菜单前必须有对应可交互页面，不设空总览占位。
