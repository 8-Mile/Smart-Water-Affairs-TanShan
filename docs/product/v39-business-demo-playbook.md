## 一、只优化当前DEMO

原顶部“模拟场景”改为“演示路线”入口，小屏使用简短浮动入口，不增加侧栏菜单。业务导览分三条：

1. **暴雨污染水（3步）**：强降雨60mm与污染来水 → 逐池工程依据 → 返回模型并保存模拟快照。重点解释港口污染径流收集、调蓄及合法消纳约束，不把未经核实的管网、池容和去向当成事实。
2. **供水泵组异常（6步）**：明确启用泵组故障情景 → 值班员待办 → 定位P-002并确认原告警 → 查阅原维修结果 → 管理者验收 → 独立核查告警关闭。原故障场景WO-2026-014处于“待验收”，导览会按实际状态提示不必重复提交。
3. **三水源与成本（2步）**：核算并保存本轮新WS供水草稿 → 按精确WS编号导入成本页，人工确认重算后保存相对应的GNB草稿，不能误用旧方案。

## 二、演示操作

打开原首页，点击顶部“演示路线 · 当前场景”，选择路线。导览显示当前步骤、讲解重点、原模型业务状态、适用岗位及返回/下一步。进入业务页面时默认收起，避免遮挡工艺和操作按钮；点击小条可展开。

进度只存放当前浏览器会话，刷新后可继续；结束导览不删除本地记录。启用故障场景、转换演示角色均需明确确认，导览不会自动确认告警、派工、归档或关闭事件。

强降雨完成标识来自本轮新快照；三水源完成标识来自本轮新WS与对应GNB记录；设备异常来自原P-002告警和WO-2026-014工单状态，没有独立复制数据。

## 三、工程真实性边界

所有测点与费用为MOCK或人工输入，污染水合法去向、管网实际连通、水质达标、实际节约、设备复归和SCADA控制均未在本轮证实。演示结论仅供评审与业务方案讨论。
