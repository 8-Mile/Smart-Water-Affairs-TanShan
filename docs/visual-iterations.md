# 唐港港区视觉还原迭代记录

## 基准

- 设计图：`/Users/8-mile/设计图/2026.12.21设计图/唐港智慧水务港区总览-1.png`
- CAD：`frontend/public/tanggang/cad/l1-v2_2/scene-v2.2.json`、`l1-v2_6/spatial-candidates-v2.6.json`

- 问题收敛目标：遗留问题 <5 个。

## 第 1 轮 · 机位与底盘

- 日期：2026-11-22
- 改动：
  - 修正默认机位：原先走 `?cam` 分支，fov 9.78、距离 320 的长焦全景；改为 fov 32、距离 170、俯角 30°、targetZ -4。
  - 从 CAD「00-总图01推荐 道路中心线」生成 41 条 7m 车行道，补路缘与中心虚线。
  - 天空换为 `syferfontein_clear_puresky_2k.hdr`，环境强度 0.75 → 0.92。
  - 太阳改到 `(64,104,-44)`，阴影朝屏幕右下，与设计图一致。
- 对比：
  - 构图已能看到堆场、右侧办公区、底部码头与海面，接近设计图的整体关系。
  - 道路目前只覆盖办公区和南侧主路，堆场环线仍是大片场坪。
  - 周边树林过密，设计图是厂区道路与建筑。
  - 海面只占底部一条，天空几乎不可见。
- 性能：377 calls / 1.02M 三角面 / 59.9fps。
- 遗留问题：
  1. 海面占比不足，码头与船被裁。
  2. 周边树林过多，缺少厂区道路与围墙。
  3. 天空占比过低，地平线缺少雾化过渡。
  4. 堆场环线与停车场的路面、标线缺失。
  5. 堆体表面仍有细密网格感，三色区分弱。
  6. 集水池水面过亮，像塑料槽。

## 第 2 轮 · 海侧构图与林带

- 日期：2026-11-22
- 改动：
  - 相机改到海侧：pitch 22°、距离 180、fov 36、targetZ 12，海面成为前景。
  - 移除东西两侧整圈密林，只保留北侧远景林带，露出厂区边界。
- 对比：
  - 海面占画面约 30%，两艘船与橙色装卸设备入画，堆场 16 堆完整可数。
  - 构图关系已接近设计图：海在下、堆场居中、办公区在右。
  - 天空仍不可见，顶部被北侧绿地和林带占据。
  - 海面纹理重复、偏灰，缺少白沫、湿痕和船体倒影。
- 性能：377 calls / 666k 三角面 / 59.9fps。
- 遗留问题：
  1. 天空不可见，地平线没有天空与雾的过渡。
  2. 海面缺白沫、湿痕、船体接触暗带，纹理重复。
  3. 堆体表面网格感明显，三色区分弱。
  4. 集水池水面过亮，像塑料槽。
  5. 码头岸线、护舷、系缆桩细节缺失。
