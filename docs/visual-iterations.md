## 第 8 轮 · 堆场去贴图化与林带收敛

- 日期：2026-11-23
- 问题：用户反馈“堆场和树一看就是贴图，太假了”。远景堆面出现规则迷宫/鱼鳞状亮暗斑。
- 根因（关键）：`build_stockpiles.py` 的四边形顶点顺序写成 `(a, b, a+1, b+1)`，是一个自交的“蝴蝶结”。Blender 三角化与法线因此全部错乱，堆面在远景读成棋盘状花斑；此前误判为照片贴图/阴影。
- 改动：
  - 四边形环绕修正为 `(a, a+1, b+1, b)`，重建 16 堆 GLB（v=15）。
  - 堆体材质彻底去掉照片 color/normal/rough 贴图，改为“深色基色 + 顶点色顶亮坡暗”；煤 `#3c434a`、褐矿 `#6f5940`、灰矿 `#7c8285`，每堆仍按锚点做确定性明度差。
  - 顶点色去掉逐顶点 grain 与高频 rough 起伏，避免法线抖动；坡面起伏只保留低频 bump。
  - 移除堆场正常贴图与法线平铺（`v=8`→`v=15` 的缓存版本逐次递进）。
  - 树木：北侧林带密度 30%→20%、后排间距 2.9/3.1→3.8/3.9 且高矮跨度加大；远景林冠体块大幅削减（剔除率 8%→42%）；林下灌木只保留 2/3；树冠高宽比 0.56–1.54 随机，打破“绿色球墙”。
  - 阴影 `normalBias 0.05→0.16`、`bias -0.0005→-0.0008`，降低坡面自遮挡。
- 对比（1672×941 默认机位）：
  - 堆面迷宫/鱼鳞纹完全消失，呈现平滑锥形堆体与清晰堆脊。
  - 树线出现参差缺口与高矮变化，不再是一整圈规整绿球。
- 性能：397 calls / 394.8k 三角面 / 59.9fps（median 16.7ms）。
- 遗留问题：
  1. 天空只有灰蓝渐变，缺少云。
  2. 海面岸线白沫偏弱。
  3. 堆体仍偏“光滑香肠”，缺少坡脚滑落痕迹与湿煤反光差异。
  4. 集水池浅色池沿占比过大，仍偏亮。
  5. 码头细节尺寸过小，默认机位不可辨。

## 第 11 轮 · 堆间通道去黑、海色校准与岸线对比

- 日期：2026-11-23
- 问题：堆场堆间通道与堆脚读成近黑条；海色与设计图偏差；系缆桩和浅色地坪糊在一起。
- 根因：CAD 道路中心线铺的是深色沥青照片贴图（`roadPbr` 挂 `pbr/asphalt` + `#969c94`），在堆间通道读成黑条，此前误判为接触阴影。像素实测通道为 RGB(29,32,32)，去掉沥青贴图后回到 (128,134,130)。
- 改动：
  - 场坪面层：道路材质改用混凝土贴图、基色 `#a7aca4`，删除沥青贴图加载；堆场垫层 `coalPad` `#474f4d` → `#8a8f88`，恢复设计图的灰色地坪。
  - 接触阴影：程序化堆体暗带 `width+1.2 / length+1.2` → `+0.7`、透明度 `.72` → `.58`；GLB 堆体由 1.18× 纯黑平面改为 1.06× 足印软边贴图（`footprintShadow`），只在堆脚留一圈窄脏边。
  - 尘带：宽度 `1.45 / 1.35` → `0.95`，透明度 `.75` → `.50`，保留堆脚脏边但不再压暗整条通道。
  - 海色：`#0d6070 / #4ab8bd` → `#0e5f72 / #46a9ba`（按设计图底部水域实测 RGB(64,136,163) 提亮并加蓝）。
  - 系缆桩 `#79848a` → `#4e565b`；煤堆 roughness `.56` → `.64`、`envMapIntensity .38` → `.30`，收敛堆顶高光。
- 对比（1672×941）：
  - 堆间通道由近黑条变为灰色混凝土地坪，白色中心虚线恢复为细线，堆脚仍保留窄暗边与散落碎煤。

- 遗留问题：

  2. 码头护舷与系缆桩受俯视角与船舶遮挡限制，默认机位仍不易辨认。
