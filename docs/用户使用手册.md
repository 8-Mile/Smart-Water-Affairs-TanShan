## 1. 引言

### 1.1 编写目的

本手册用于指导最终用户正确使用新一代泵站运维运营管理平台，说明系统各功能模块的用途、界面构成、操作步骤、字段含义与权限约束。读者按本手册操作即可完成日常运维业务，无需了解系统的技术实现。

### 1.2 适用范围

本手册适用于本系统 V1 版本（后端 API v1、前端 Harbor 主题）的全部功能模块，覆盖工作台、告警、维修、实时监控、设备资产、调度指令、数据统计、巡检、档案、系统管理与智能助手。

本手册不描述以下内容：系统部署与运维（见《部署说明》）、接口开发与二次开发、数据库结构设计。上述内容请参阅对应的技术文档。

### 1.3 读者对象

| 读者类型 | 关注章节 | 阅读建议 |
|---|---|---|
| 一线操作员 | 第 2、3、4 章 + 第 5 章中本角色可用的操作 | 重点阅读「操作前提」与「操作步骤」中标注为操作员的路径 |
| 业务领导 | 第 2、4 章 + 第 5 章全部业务模块 | 重点掌握派发、审核、验收类操作 |
| 系统管理员 | 第 5.10 节系统管理 + 附录 A | 负责账号、角色、菜单、权限与 SCADA 接入配置 |
| 项目运维人员 | 全篇 + 附录 B 状态字典 | 用于培训交付与用户答疑 |

### 1.4 术语与缩略语

| 术语 | 说明 |
|---|---|
| 台账 | 设备的基础档案信息，含编号、分类、位置、厂商、状态等 |

## 2. 系统概述

### 2.1 系统简介

新一代泵站运维运营管理平台是一套面向**泵站（供水/排水泵机组）集中运维与运营**的一体化管理软件。系统以「**设备台账为底座、告警与巡检为感知、维修工单为闭环、数据统计为决策**」为主线，将设备管理、告警处置、巡检、维保、维修、调度、档案与统计分析贯通为一条完整的运维业务链，实现泵站运维的数字化、流程化与可追溯。

### 2.2 功能概览

| 序号 | 模块 | 路由入口 | 核心职责 | 可用角色 |
|---|---|---|---|---|
| 1 | 工作台 | `/dashboard` | 全局态势、待办任务、机组运行状态与运行动态 | 领导、操作员 |
| 2 | 告警中心 | `/alarm/realtime` | 实时/历史告警监测、处置与规则维护 | 领导、操作员 |
| 3 | 维修工单 | `/repair/list` | 人工报修、派单、完工、验收全流程 | 领导、操作员 |
| 4 | 实时监控 | `/scada/monitor` | SCADA 测点实时值监测、仿真控制、测点配置 | 领导、操作员（测点配置仅领导） |
| 5 | 设备资产 | `/equipment/list`、`/maintenance/plans`、`/equipment/maintenance-vendors` | 设备台账、设备维护（维保计划）、厂商管理 | 领导、操作员 |
| 6 | 调度指令 | `/dispatch/stats` | 调度指令的发布、审核、执行与反馈闭环 | 领导、操作员 |
| 7 | 数据统计 | `/water/stats`、`/energy/stats` | 供水统计、耗能分析、水电耗对比 | 领导、操作员 |
| 8 | 设备巡检 | `/inspection/tasks` | 巡检计划、任务派发、认领执行、记录提交 | 领导、操作员 |
| 9 | 档案管理 | `/archive` | 各类运维与设备资料的分类归档 | 领导、操作员 |
| 10 | 系统管理 | `/system/departments`、`/system/users`、`/system/logs`、`/system/scada` | 组织架构、用户角色菜单权限、操作日志、SCADA 接入 | 仅超级管理员（操作日志领导亦可查看） |
| 11 | 智能助手 | 悬浮入口 → `/ai/chat` | 自然语言问答与辅助操作 | 全部角色 |

### 2.3 运行环境与访问方式

- **访问方式**：浏览器（推荐 Chrome / Edge 最新版）访问系统部署地址，登录后进入。
- **显示适配**：桌面端为最佳体验（建议分辨率 ≥ 1440×900）；窄屏（≤1024px）侧边栏自动收起为图标栏；移动端各列表与卡片自动切换为响应式单列排布。
- **账号来源**：账号由超级管理员在「系统管理 → 权限管理 → 用户管理」中创建并分配角色。
- **网络要求**：需能访问系统部署地址及后端 API 服务；若页面提示「无法连接服务器，请检查网络或稍后重试」，说明前端无法连通后端服务，请联系运维人员检查服务状态。

### 2.4 用户角色与权限模型

#### 2.4.1 三类内置角色

系统内置三类角色（`sys_role.code`），角色决定**菜单可见范围、按钮操作权限、数据可见范围**三层差异。**权限以角色为唯一来源**：前端按登录接口下发的权限码控制菜单与按钮显隐，后端对每个写操作接口做同名校验，越权调用直接返回 403。

| 维度 | 超级管理员 `super_admin` | 领导 `admin` | 操作员 `operator` |
|---|---|---|---|
| 系统定位 | 系统配置与账号运维 | 全局业务管理与审批 | 一线任务执行 |
| 菜单可见 | **仅「系统管理」**：组织设置、权限管理、操作日志、SCADA 接入 | 全部业务菜单 + 操作日志 | 全部业务菜单（不含系统管理） |
| 登录后落地页 | 权限管理（工作台不开放） | 工作台（全局总览） | 工作台（我的任务） |
| 按钮权限 | 全部 `sys:*` 按钮 | 全部业务按钮（不含 `sys:*`） | 仅执行、上报、反馈类按钮（见附录 A） |
| 数据范围 `data_scope` | `all`（全部） | `all`（全部） | `mine`（仅本人） |

#### 2.4.2 菜单可见矩阵

| 菜单 | 超级管理员 | 领导 | 操作员 |
|---|:--:|:--:|:--:|
| 工作台 | — | 有 | 有 |
| 告警中心 | — | 有 | 有 |
| 维修工单 | — | 有 | 有 |
| 实时监控 | — | 有 | 有 |
| 设备资产（台账 / 维护 / 厂商） | — | 有 | 有 |
| 调度指令 | — | 有 | 有 |
| 数据统计（供水 / 耗能） | — | 有 | 有 |
| 设备巡检 | — | 有 | 有 |
| 档案管理 | — | 有 | 有 |
| 系统管理 · 组织设置 | 有 | — | — |
| 系统管理 · 权限管理 | 有 | — | — |
| 系统管理 · 操作日志 | 有 | 有 | — |
| 系统管理 · SCADA 接入 | 有 | — | — |
| 智能助手（悬浮入口） | 有 | 有 | 有 |

#### 2.4.3 数据范围

- `all`：可见全部业务数据。领导、超级管理员默认使用此范围。
- `mine`：仅可见与本人相关的数据（本人发布、本人被指派、本人认领）。操作员默认使用此范围。

数据范围在**列表查询层面硬过滤**，不是前端隐藏，因此操作员即使手工构造查询条件也看不到他人数据。

#### 2.4.4 权限作用机制

| 层级 | 作用点 | 表现 |
|---|---|---|
| 菜单权限 | 侧边栏、页面访问 | 未授权的菜单不显示；直接输入 URL 访问会跳转 403 页 |
| 按钮权限 | 页面内操作按钮 | 未授权按钮**不渲染**（不是置灰） |
| 接口权限 | 后端写操作 | 越权调用返回 403「无操作权限：缺少 xxx」 |
| 数据权限 | 查询过滤 | `mine` 角色仅返回本人数据 |

权限调整后，对应账号需**重新登录**（或切换标签页触发菜单刷新）方可完全生效。

## 3. 环境准备

### 3.1 登录

**操作前提**：已由超级管理员创建账号并分配角色。

1. 打开系统访问地址，进入登录页。
2. 输入**用户名**与**密码**（登录页默认预填演示账号，正式环境请勿使用默认凭据）。
3. 点击「登录」按钮（输入框内按回车同样可提交）。
4. 登录成功后自动跳转：
   - 领导、操作员 → 跳转至**工作台**；
   - 超级管理员 → 直接进入**权限管理**（工作台对其不开放）。

> 若从受保护页面被重定向到登录页，登录后会**自动回到原访问地址**。

### 3.2 退出登录

点击右上角**头像**，在弹出卡片中点击「**退出登录**」，系统清除本地登录态并返回登录页。

> 登录状态过期后，任意操作会提示「长时间未操作已退出登录」并自动返回登录页，重新登录即可。

### 3.3 界面总览

| 区域 | 位置 | 说明 |
|---|---|---|
| 侧边导航栏 | 左侧 | 按当前角色显示可访问菜单，支持逐级展开；顶部 Logo 点击可回到默认首页 |
| 折叠按钮 | 左上角 | 切换侧边栏展开/收起 |
| 页面标题 | 顶栏中部 | 显示当前页面名称 |
| 实时时钟 | 顶栏右侧 | 显示年月日、星期与实时时间 |
| 全屏按钮 | 顶栏右侧 | 切换浏览器全屏显示 |
| 通知铃铛 | 顶栏右侧 | 显示未读通知数量，点击查看通知列表，支持「全部已读」与跳转定位 |
| 用户菜单 | 顶栏右侧头像 | 显示当前用户姓名/账号，提供退出登录 |
| 智能助手 | 右下角悬浮球 | 点击展开智能问答面板 |

## 4. 快速入门

### 4.1 通用交互规范

| 交互 | 说明 |

| 列设置 | 表格右上角勾选需要显示的列 |
| 导出 | 导出当前筛选结果为 Excel，文件名按模块命名 |
| 刷新 | 重新拉取最新数据 |

| 行操作 | 每行右侧「查看 / 编辑 / 删除 / 业务动作」按钮，按权限显隐 |
| 详情抽屉 | 点击「查看」从右侧滑出，集中展示完整信息，部分抽屉底部带业务操作按钮 |

| 消息提示 | 操作结果以顶部消息条提示；失败时显示后端返回的具体原因 |

### 4.2 首次使用建议路径

**操作员**：

1. 登录 → 工作台查看「我的告警 / 我的待办工单 / 我的待办巡检 / 我的待办维保」。
2. 进入告警中心处理被指派的告警，或进入维修工单对本人任务「完工提交」。
3. 进入设备巡检认领任务并提交巡检记录。
4. 进入调度指令查看下发给本人的指令，执行完毕后反馈。

**领导**：

1. 登录 → 工作台查看全局运行态势与今日数据。
2. 每日巡检「告警中心」：对未处置告警执行「维修处理」，在「维修工单」中派单。
3. 审阅「调度指令」中待审批的指令并给出审核意见。
4. 周期性维护「设备维护」维保计划与「设备巡检」巡检计划。

**超级管理员**：

1. 登录后进入权限管理，先建组织（部门/班组），再建用户并分配角色。
2. 在角色管理中按岗位勾选菜单与按钮权限。
3. 在 SCADA 接入中完成数据源配置。

## 5. 功能操作说明

> 本章每个模块统一按六段说明：**功能说明、操作前提、界面说明、操作步骤、字段说明、注意事项**。操作步骤按角色分列，请只关注与本人角色相关的路径。

### 5.1 工作台（`/dashboard`，权限 `dashboard:view`）

#### 5.1.1 功能说明

系统门户，按角色呈现两套布局——领导为**全局总览**，操作员为**我的任务**。用于快速掌握泵站运行态势、当日数据与本人待办。

#### 5.1.2 操作前提

- 具备菜单权限 `dashboard:view`（领导、操作员默认具备）。
- 超级管理员不可访问本页，登录后直达权限管理。

#### 5.1.3 界面说明

**领导视图（全局总览）**

- **左列**：上部为**机组运行状态**通栏工艺图（5 台机组，徽章显示「运行中 / 停止」），下部为 2×2 图表：供水量·计划对比、电耗·吨水电耗、前后池水位、能耗趋势（支持日/周切换）。
- **右列**：综合告警、待处理工单、近 7 日供水量。
- **今日数据总览窄栏**（最右侧）：今日供水/用电/告警/工单 4 张指标卡 → 能耗概览（电费、峰谷平电量环图、电价参考、吨水电耗、计划完成率）→ 机组运行时长排行 → 机组能效排行（单耗 kWh/m³）→ 告警/工单概览 → **日期日历**（点击历史日期，整页切换为该日数据）。

**操作员视图（我的任务）**

- **上**：机组运行状态通栏工艺图（图片自适应铺满，5 台机组徽章横向对齐机组正上方）。
- **下**：一行四张待办卡——**我的告警 / 我的待办工单 / 我的待办巡检 / 我的待办维保**，均只列本人数据，卡片内「更多」可跳转对应模块并自动带上本人筛选条件。

#### 5.1.4 操作步骤

**查看机组详情（两角色通用）**

1. 在机组运行状态图中点击任一机组徽章 → 弹出该机组信息面板（不遮挡被选机组）。
2. 面板内容：① 运行状态心电图与运行/停止 ② 台账信息（设备编号、类型）③ 实时工况（运行电流、有功功率、轴承温度、本次运行时长）④ 运维情况（未闭环工单、未闭环告警）。
3. 点击面板底部「**查看详情**」→ 跳转设备台账并自动定位、高亮该设备。
4. 点击面板以外区域或面板右上角关闭按钮收起。

**切换统计日期（领导）**

1. 在最右侧日期日历中点击目标日期。
2. 整页数据切换为该日数据；再次点击「今天」返回当日。

**处理待办（操作员）**

1. 在「我的告警 / 我的待办工单 / 我的待办巡检 / 我的待办维保」卡片中查看条目。
2. 点击卡片内「更多」→ 跳转对应模块，列表自动带上本人筛选条件。
3. 点击具体条目 → 跳转并高亮定位该条记录。

#### 5.1.5 字段说明

| 指标 | 说明 |
|---|---|
| 运行中 / 停止 | 机组当前运行状态，由设备 `running_status` 决定 |
| 今日供水量 | 当日累计供水，单位 m³ |
| 今日用电量 | 当日累计用电，单位 kWh |
| 吨水电耗 | 用电量 ÷ 供水量，单位 kWh/m³，越低越优 |
| 计划完成率 | 实际供水量 ÷ 计划供水量 |
| 未闭环工单 / 告警 | 尚未验收归档的工单与尚未关闭的告警数量 |

#### 5.1.6 注意事项

- 工作台的数据范围与角色绑定：领导看全局，操作员只看本人。
- 图表与日历数据按所选日期整体切换，切换后所有区块同步为该日数据。
- 页面数据非实时推送，需要最新数据时刷新浏览器或切换日期再切回。

### 5.2 告警中心（`/alarm/realtime`，权限 `alarm:realtime`）

#### 5.2.1 功能说明

集中监测泵站设备实时/历史告警，并完成告警的指派与处置闭环。告警是维修工单的主要来源之一。

#### 5.2.2 操作前提

- 具备菜单权限 `alarm:realtime`。
- 「告警规则」「告警类型」页签需具备 `alarm:rule:*` / `alarm:type:*` 权限（默认仅领导）。
- 转单处置需 `alarm:handle`（领导、操作员默认具备）。

#### 5.2.3 界面说明

**页签构成**

| 页签 | 说明 | 可见条件 |
|---|---|---|
| 实时告警 | 当前活跃告警列表（默认） | `alarm:realtime` |
| 历史告警 | 已处置告警归档查询 | `alarm:realtime` |
| 告警规则 | 告警判定规则维护 | `alarm:rule:*` |
| 告警类型 | 告警分类维护 | `alarm:type:*` |

**主要表格列**：规则/设备、告警等级、告警内容、设备、位置、触发值、状态、指派、时间、操作。

**告警等级**

| 等级 | 中文 | 颜色 |
|---|---|---|
| 1 | 一类 | 红 |
| 2 | 二类 | 橙 |
| 3 | 三类 | 蓝 |

**告警状态**

| 状态码 | 中文 | 说明 |
|---|---|---|
| `pending` | 未处理 | 已产生、已关联工单但尚未处理 |
| `processing` | 处理中 | 已派工、维修处理中 |
| `pending_accept` | 待验收 | 维修完成，等待验收 |
| `closed` | 已关闭 | 已验收关闭 |
| （派生）| **待指派** | 未闭环且未关联维修工单 |

**快捷统计卡**：未处理 / 处理中 / 待指派 / 全部数据（点击筛选）。其中「未处理」「处理中」为对应状态且已派工；「待指派」为未闭环且未关联工单。

#### 5.2.4 操作步骤

**处置告警（领导 / 操作员）**

1. 进入「告警中心 → 实时告警」，按等级、状态或关键字筛选目标告警。
2. 点击行内「**维修处理**」→ 系统生成一张关联该告警的维修工单，处理人默认为当前操作人。
3. 前往「维修工单」继续派单、完工、验收流程。告警状态随工单进度自动联动：未处理 → 处理中 → 待验收 → 已关闭。

**维护告警规则（仅领导）**

1. 切换到「告警规则」页签。
2. 点击「新增规则」或「复制规则」（以现有规则为模板快速新建）。
3. 填写规则名称、关联设备/测点、判定条件、告警等级、启用状态后保存。
4. 行内「编辑」「删除」可修改或移除规则。

**维护告警类型（仅领导）**

1. 切换到「告警类型」页签。
2. 点击「新增」填写类型名称、编码、说明后保存；行内可编辑、删除。

**查询历史告警（领导 / 操作员）**

1. 切换到「历史告警」页签。
2. 按时间范围、等级、设备筛选，查看已闭环告警的处置记录。

#### 5.2.5 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 规则名称 | 是 | 规则标识名称 |
| 关联设备/测点 | 是 | 规则适用的设备或 SCADA 测点 |
| 判定条件 | 是 | 触发阈值与比较关系（如 温度 > 80） |
| 告警等级 | 是 | 一类 / 二类 / 三类 |
| 启用状态 | 否 | 停用后不再产生该类告警 |
| 类型名称 / 编码 | 是 | 告警分类标识 |

#### 5.2.6 注意事项

- 「待指派」不是独立状态码，而是「未闭环且未关联工单」的展示细分，需先执行「维修处理」生成工单后才能进入正常处置流程。
- 告警状态由工单进度驱动，**不要手工修改**；关闭告警的唯一途径是工单验收通过。
- 操作员数据范围为 `mine`，只能看到派给本人的告警。

### 5.3 维修工单（`/repair/list`，权限 `repair:list`）

#### 5.3.1 功能说明

承载设备故障的**人工报修与告警转单**，并完成派单、完工、验收的全流程闭环。系统内所有维修类工作最终都收敛到本模块。

#### 5.3.2 操作前提

- 具备菜单权限 `repair:list`。
- 各动作的按钮权限见下表；操作员的完工提交仅对本人被指派的工单可用。

#### 5.3.3 界面说明

- **KPI 统计卡**：待派单 / 已派发 / 待验收 / 已归档 / 已驳回（点击筛选）。
- **查询条件**：工单号、设备名称、状态。
- **主要表格列**：工单编号、设备名称、故障描述、处理状态、处理人、时间、操作。

**工单状态**

| 状态码 | 中文 | 颜色 |
|---|---|---|
| `pending_dispatch` | 待派单 | 蓝 |
| `processing` | 已派发 | 橙 |
| `pending_accept` | 待验收 | 紫 |
| `archived` | 已归档 | 绿 |
| `rejected` | 已驳回 | 灰 |

#### 5.3.4 操作步骤

**人工报修（领导 / 操作员）**

1. 点击列表上方「**人工报修**」；也可在设备台账行内点击「报修」。
2. 填写设备、故障描述、紧急程度，可上传现场照片。
3. 提交后工单进入「待派单」。

**派单（仅领导）**

1. 在待派单工单行点击「**派单**」。
2. 选择处理人、填写派单说明与处理期限。
3. 确认后工单进入「已派发」，处理人手机端/通知中心收到提醒。

**完工提交（操作员本人 / 领导）**

1. 在已派发且处理人为本人的工单行点击「**完工提交**」。
2. 填写处理过程、处理结果，上传完工照片。
3. 提交后工单进入「待验收」。

**验收（仅领导）**

1. 在待验收工单行点击「**验收**」，查看维修完成情况与图片。
2. 选择「验收通过」→ 工单**自动归档**，关联告警同步关闭。
3. 选择「驳回」并填写原因 → 工单退回「已派发」，处理人需返工。

**驳回工单（仅领导）**

1. 在待派单工单行点击「**驳回**」并填写驳回意见。
2. 工单变为「已驳回」，如需继续维修需重新发起报修。

#### 5.3.5 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 设备 | 是 | 选择报修设备 |
| 故障描述 | 是 | 现象、部位、影响范围 |
| 紧急程度 | 是 | 一般 / 紧急 / 特急 |
| 现场照片 | 否 | 支持多张 |
| 处理人 | 是 | 派单时选择 |
| 派单说明 | 否 | 处理要求与注意事项 |
| 处理过程 / 结果 | 是 | 完工提交时填写 |
| 验收结论 | 是 | 通过 / 驳回（驳回须填原因） |

#### 5.3.6 注意事项

- 验收通过后工单**不可再修改**，只能查看。
- 操作员只能对**本人被指派**的工单点「完工提交」，其他工单不显示该按钮。
- 工单被驳回后不会重新进入派单池，需重新报修。

### 5.4 实时监控（`/scada/monitor`，权限 `scada:monitor`）

#### 5.4.1 功能说明

展示 SCADA 采集的测点实时值与质量状态，监控采集运行情况；具备权限的管理人员可在此维护测点定义、控制仿真运行、手动注入测点值。

#### 5.4.2 操作前提

| 操作 | 所需权限 | 默认具备角色 |
|---|---|---|
| 查看实时监控页与测点实时值 | `scada:monitor` | 领导、操作员 |
| 进入「测点配置」页签 | 任一 `scada:point:*` | 领导 |
| 新增测点 | `scada:point:create` | 领导 |
| 编辑测点 | `scada:point:update` | 领导 |
| 删除测点 | `scada:point:delete` | 领导 |
| 手动注入测点值 | `scada:point:inject` | 领导 |
| 启动 / 停止仿真 | `scada:sim:control` | 领导 |

#### 5.4.3 界面说明

**页签构成**

| 页签 | 说明 | 可见条件 |
|---|---|---|
| 实时监控 | 运行状态 + 实时测点值（默认） | `scada:monitor` |
| 测点配置 | 测点定义维护 | 任一 `scada:point:*` |

**运行状态卡**：运行状态（仿真运行中 / 已停止）、模式与端点、采集周期与 Tick 计数（含最近采样点数）、配置的 OPC 端点，以及操作按钮。

**告警提示条**：
- 最近错误：采集过程中最近一次异常信息（红色）。
- 数据缺失提醒：有测点超过 5 分钟未更新时的数量提示（橙色）。

**实时测点值表格列**：测点、NodeId、当前值、类型、质量、描述、时间戳、新鲜度。

**大屏模式**：页面右上角「大屏 / 浅色」按钮切换本页深色大屏显示，仅影响当前页，不改变全局主题。

#### 5.4.4 操作步骤

**查看实时数据（领导 / 操作员）**

1. 进入「实时监控」页签。
2. 在「过滤测点」输入框输入测点名并回车，快速过滤目标测点。
3. 查看「当前值」与「质量」列：质量为 `Good` 表示采集正常；`新鲜度`列为「正常」表示数据在有效期内。
4. 点击「刷新」重新拉取数据。

**启动 / 停止仿真（仅领导）**

1. 在运行状态卡点击「**启动仿真**」（运行中时该按钮置灰）。
2. 状态显示「仿真运行中」，周期与 Tick 计数开始增长。
3. 需要停止时点击「**停止**」。

**新增测点（仅领导）**

1. 切换到「测点配置」页签，点击「**新增测点**」。
2. 填写测点名称、NodeId、值类型、单位、描述、仿真基值/振幅/周期、启用采集与状态。
3. 保存后测点出现在列表中，采集启用后开始产生数据。

**编辑 / 删除测点（仅领导）**

1. 在测点行点击「编辑」修改配置并保存。
2. 点击「删除」并确认后移除该测点。

**手动注入测点值（仅领导）**

1. 在测点行点击「**注入**」。
2. 输入目标值（数值或 `true`/`false`），点击「注入」。
3. 实时测点值列表刷新后可看到注入结果。

#### 5.4.5 字段说明

**测点定义**

| 字段 | 必填 | 说明 |
|---|---|---|
| 测点名称 `tag_name` | 是 | 采集标签，如 `PLC1.Flow` 或 `700` |
| NodeId | 是 | OPC UA 节点标识，如 `ns=1;i=686` |
| 值类型 | 否 | number / bool / string |
| 单位 | 否 | 如 m³/h、kW、℃ |
| 描述 | 否 | 测点业务含义 |
| 仿真基值 / 振幅 / 周期 | 否 | 仿真模式下的数值生成参数 |
| 启用采集 | 否 | 关闭后不参与采集 |
| 状态 | 否 | 正常 / 禁用 |

**实时值展示**

| 列 | 说明 |
|---|---|
| 当前值 | 最近一次采集值，数值保留三位小数 |
| 质量 | `Good` 为正常，其他为异常 |
| 时间戳 | 最近一次采集时间 |
| 新鲜度 | 正常 / 滞后 / 缺失，超过 5 分钟未更新判为缺失 |

#### 5.4.6 注意事项

- 测点配置属**管理职能**，操作员默认看不到该页签（不是置灰，而是不渲染）。
- 手动注入仅影响仿真/演示数据，不写入真实采集链路，请勿在正式环境中用于伪造生产数据。
- 出现「数据缺失提醒」时，先检查 SCADA 接入配置与采集服务是否运行，再排查网络与 OPC 端点。
- 大屏模式为页面级显示切换，不改变数据范围与权限。

### 5.5 设备资产

设备资产模块由三部分构成：**设备台账**、**设备维护（维保计划）**、**厂商管理**。

#### 5.5.1 设备台账（`/equipment/list`，权限 `eq:list`）

**功能说明**

以设备档案树 + 详情区的方式管理全站设备，是告警、巡检、维保、维修的数据底座。

**操作前提**

- 具备菜单权限 `eq:list`。
- 「设备分类」「运行记录」页签按 `eq:type:*` / `eq:run:event` 权限显示。
- 新增、编辑、删除设备默认仅领导具备（`eq:create` / `eq:update` / `eq:delete`）。

**界面说明**

- **页面构成**：KPI 统计卡（设备总数 / 在线 / 待检修 / 故障 / 检修中等）、搜索栏、左侧设备档案树、右侧设备详情区。
- **页签**：设备列表、设备分类、运行记录（后两者按权限显示）。
- **设备列表主要列**：设备名称、设备编号、设备分类、部署位置、运行状态、维护状态、操作。
- **设备档案树**：按层级懒加载，展开节点才请求下级设备；顶部提供「全部 / 运行中 / 有告警」快捷筛选与搜索。

**运行状态**：`running` 运行中 / `stopped` 已停机。
**维护状态**：`normal` 正常 / `need_maintain` 需保养 / `fault` 故障待修。
**派生检修状态**：`pending` 待检修（橙，由未闭环维修工单投影）/ `overhaul` 检修中（紫）。

**主要操作与权限**

| 按钮 | 权限码 | 领导 | 操作员 |
|---|---|:--:|:--:|
| 新增设备 | `eq:create` | 有 | — |
| 编辑设备 | `eq:update` | 有 | — |
| 删除设备 | `eq:delete` | 有 | — |
| 导出设备台账 | `eq:list` | 有 | 有 |
| 设备行内「报修」 | `repair:create` | 有 | 有 |
| 设备分类 增/改/删 | `eq:type:create` / `eq:type:update` / `eq:type:delete` | 有 | — |
| 记录启停 | `eq:run:event` | 有 | 有 |

**操作步骤**

*浏览与定位（领导 / 操作员）*

1. 在左侧设备档案树中逐级展开，或使用搜索框按机组/设备名称检索。
2. 点击树中设备节点，右侧详情区展示该设备概况与下属设备。
3. 点击顶部 KPI 卡可按状态筛选；再次点击取消。

*新增设备（仅领导）*

1. 点击左侧树面板右上角「+」按钮（或列表上方「新增设备」）。
2. 填写设备名称、编号、分类、部署位置、关联测点、厂商、维保期限、运行状态、维护状态、关键日期与备注。
3. 保存后设备出现在档案树对应层级。

*编辑 / 删除设备（仅领导）*

1. 在设备详情或行内点击「编辑」修改后保存。
2. 点击「删除」并确认；已产生业务数据的设备建议改为停用而非删除。

*设备报修（领导 / 操作员）*

1. 在设备行内点击「报修」。
2. 填写故障描述、紧急程度、现场照片后提交，进入维修工单流程。

*登记启停（领导 / 操作员）*

1. 切换到「运行记录」页签。
2. 点击「记录启停」，选择启/停类型与发生时间，填写说明后保存。
3. 页面同步更新累计运行时长与启停统计。

**字段说明**

| 字段 | 必填 | 说明 |
|---|---|---|
| 设备名称 | 是 | 设备显示名 |
| 设备编号 | 是 | 唯一编号 |
| 设备分类 | 是 | 取自设备分类字典 |
| 部署位置 | 是 | 所属泵站/位置 |
| 关联变量 ID | 否 | SCADA 测点 ID，多个以逗号分隔 |
| 生产厂商 / 维保厂商 | 否 | 取自厂商管理 |
| 维保期限（天） | 否 | 用于维保到期提醒 |
| 运行状态 | 是 | 运行中 / 已停机 |
| 维护状态 | 是 | 正常 / 需保养 / 故障待修 |
| 连续运行小时 | 否 | 当前连续运行时长 |
| 生产 / 采购 / 首次运行日期 | 否 | 设备全生命周期节点 |

**注意事项**

- 设备分类被设备引用时不可删除，需先调整设备分类。

### 5.6 调度指令（`/dispatch/stats`，权限 `dispatch:stats`）

#### 5.6.1 功能说明

承载上级指令与内部指令的**发布、审核、执行、反馈**闭环。指令发布后需经领导审核，审核通过方可下发执行，执行人完成后反馈结果，全过程留痕可追溯。

#### 5.6.2 操作前提

| 操作 | 所需权限 | 默认具备角色 |
|---|---|---|
| 查看指令列表与统计 | `dispatch:stats` | 领导、操作员 |
| 新建指令 | `dispatch:create` | 领导、操作员 |
| 编辑指令 | `dispatch:update` | 领导；操作员仅可编辑本人发布的待审批指令 |
| 删除指令 | `dispatch:delete` | 领导；操作员仅可删除本人发布的待审批指令 |
| 审核指令 | `dispatch:audit` | 领导 |
| 执行完毕反馈 | `dispatch:execute` | 领导、操作员（被指派人优先） |

#### 5.6.3 界面说明

- **KPI 统计卡**：全部指令（含今日新增）、待处理指令（已审批待执行）、待审批指令（等待领导复核）、执行完成率（已完成 / 总数）。点击可筛选。
- **搜索条件**：审核状态、时间范围、关键字（内容 / 编号 / 执行人）。
- **主要表格列**：序号、指令编号、类型、指令内容、发布人、发布时间、优先级、审核、执行、操作。
- **操作列**：查看、审核、编辑、删除、执行完毕（按权限与状态动态显示）。

**指令类型**

| 取值 | 中文 |
|---|---|
| `superior` | 上级指令 |
| `internal` | 内部指令 |

**优先级**：`normal` 一般 / `important` 重要 / `urgent` 紧急。

**审核状态**

| 状态码 | 中文 | 说明 |
|---|---|---|
| `pending` | 待审批 | 已发布，等待领导审核 |
| `approved` | 已通过 | 审核通过，可下发执行 |
| `rejected` | 已驳回 | 审核不通过，流程终止 |

**执行状态**：`pending` 待执行 / `done` 已完成。

#### 5.6.4 操作步骤

**新建指令（领导 / 操作员）**

1. 点击列表上方「**添加指令**」。
2. 选择指令类型（上级指令 / 内部指令），填写指令内容。
3. 选择执行人、预计完成时间，选择优先级（一般 / 重要 / 紧急）。
4. 点击「保存」。指令状态为**待审批**，等待领导审核。

**审核指令（仅领导）**

1. 在待审批指令行点击「**审核**」。
2. 弹窗展示流转时间线（发布 → 审核 → 执行）与指令详情。
3. 填写**审核意见**（必填）。
4. 点击「**审核通过**」→ 状态变为已通过，指令进入待执行；点击「**审核驳回**」→ 状态变为已驳回，流程终止。

**执行完毕反馈（被指派人 / 有执行权限者）**

1. 在已通过且待执行的指令行点击「**执行完毕**」。
2. 在「执行反馈」弹窗填写反馈内容（可选）。
3. 点击「确认完成」→ 执行状态变为已完成，完成率同步更新。

**编辑 / 删除指令（发布人 / 领导）**

1. 仅**待审批**状态的指令可编辑或删除。
2. 发布人可编辑、删除本人发布的待审批指令；具备 `dispatch:update` / `dispatch:delete` 的领导可操作全部待审批指令。
3. 点击「删除」需二次确认。

**查看指令详情（领导 / 操作员）**

1. 在任意指令行点击「查看」。
2. 右侧抽屉展示编号、类型、内容、发布人、执行人、预计完成、审核与执行状态、审核意见、执行反馈。
3. 下方「流转记录」按时间倒序展示每一步操作人、动作与说明。

**筛选与导出**

1. 使用顶部搜索栏按审核状态、时间范围、关键字组合查询。
2. 表格右上角支持列设置、导出 Excel、刷新。
3. 无匹配结果时可点击「清除筛选条件」重置。

#### 5.6.5 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 指令类型 | 是 | 上级指令 / 内部指令 |
| 指令内容 | 是 | 具体调度要求，支持多行 |
| 执行人 | 是 | 从系统用户中选择 |
| 预计完成 | 是 | 期望完成的时间点 |
| 优先级 | 是 | 一般 / 重要 / 紧急 |
| 审核意见 | 是 | 审核时必填，说明通过或驳回理由 |
| 执行反馈 | 否 | 执行完毕时的结果说明 |

#### 5.6.6 注意事项

- 指令必须经**审核通过**才能执行；待审批状态下不显示「执行完毕」。
- 已审核通过的指令不可再编辑或删除，如需变更请重新发起新指令。
- 「执行完毕」按**被指派执行人本人**或具备 `dispatch:execute` 权限者显示，避免他人代填反馈。
- 审核驳回后流程终止，需重新创建指令。
- 从工作台待办跳转时，列表会自动筛选并高亮目标指令，页面顶部出现定位提示，可手动关闭。

### 5.8 设备巡检（`/inspection/tasks`，权限 `insp:task:list`）

#### 5.8.1 功能说明

以**巡检计划**生成**巡检任务**，由执行人认领并现场巡检，提交**巡检记录**；发现异常可直接转化为维修工单。

- 「巡检计划」页签需 `insp:plan:*` 权限（默认仅领导）。
- 认领执行需 `insp:task:claim` + `insp:record:submit`（领导、操作员默认具备）。

#### 5.8.3 界面说明

- **页签**：巡检任务 / 巡检记录（默认），「巡检计划」（按 `insp:plan:*` 显示）。

**任务状态**

| 状态 | 展示 | 颜色 |
|---|---|---|
| `pending` 且未认领 | 待认领 | 橙 |
| `pending` 且已认领 | 待巡检（进行中） | 蓝 |
| `overdue` | 已超时 N 天 | 红 |
| `done` | 已完成 | 绿 |

#### 5.8.4 操作步骤

**制定巡检计划（仅领导）**

**认领并执行（操作员 / 领导）**

1. 在待认领任务行点击「**认领并执行**」→ 任务状态变为待巡检（进行中），认领人记为本人。
2. 在「执行巡检任务」弹窗中按设备分组逐项填写检查结果（正常 / 异常）与备注。
3. 填写总体备注后提交，任务变为「已完成」，同时生成巡检记录。

**提交记录（操作员 / 领导）**

1. 在「巡检记录」页签查看本人已提交的记录。
2. 未提交完成的记录可继续进入执行弹窗补录后提交。

**异常转维修（操作员 / 领导）**

1. 在巡检记录中找到标记为异常的检查项。
2. 点击「人工报修」，填写故障描述后提交，进入维修工单流程。

#### 5.8.5 字段说明

| 字段 | 必填 | 说明 |

| 巡检设备 | 是 | 可多选 |
| 班组 / 执行人 | 是 | 任务归属 |
| 任务日期 | 是 | 计划执行日期 |
| 检查结果 | 是 | 正常 / 异常 |

#### 5.8.6 注意事项

- 操作员无「巡检计划」页签，计划属管理职能。
- 超时任务显示为「已超时 N 天」，需领导重新派发或调整执行人。
- 已提交的巡检记录不可修改，若需补充请重新执行或发起新的巡检任务。

2. 点击「上传文档」，填写文档名称、选择文档类型与文件，可填备注。
3. 提交后档案出现在对应分类下。

**下载档案（领导 / 操作员）**

1. 在档案列表找到目标文档。
2. 点击「下载」，浏览器开始下载文件。

**维护分类（仅领导）**

1. 在分类树区域点击「新增分类」，填写分类名称后保存。
2. 选中分类后可编辑或删除；有档案的分类需先移走档案再删除。

**删除档案（仅领导）**

1. 在档案行点击「删除」并确认。
2. 删除后文件不可恢复，请谨慎操作。

#### 5.9.5 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 文档名称 | 是 | 档案显示名 |
| 文档类型 | 是 | 对应分类或文件类型 |
| 文件 | 是 | 上传的实体文件 |
| 备注 | 否 | 补充说明 |

#### 5.9.6 注意事项

### 5.10 系统管理（仅超级管理员）

> 领导可额外看到「操作日志」页签用于审计查询，其余页面仅超级管理员可见。

#### 5.10.1 组织设置（`/system/departments`，权限 `sys:dept:list`）

**功能说明**：维护部门、班组等组织架构，供用户归属与任务派发使用。

**界面说明**：组织树 + 详情；列含组织名称、编码、备注、状态。

**操作步骤**

1. 点击「新增」创建部门或班组，填写名称、编码、备注、上级组织。
2. 行内「编辑」「删除」维护组织；有下级或已被用户引用的组织建议先解绑。
3. 保存后组织立即出现在用户表单的部门/班组选择项中。

**主要操作与权限**：`sys:dept:create` / `sys:dept:update` / `sys:dept:delete`（超级管理员全具备）。

#### 5.10.2 权限管理（`/system/users`，权限 `sys:user:list`）

**功能说明**：管理用户账号、角色与菜单，是权限体系的配置入口。

**界面说明**：页签「用户管理」「角色管理」「菜单管理」。

- **用户管理**：列含用户名、姓名、手机、部门、班组、关联角色、状态、临时授权、操作。支持搜索、新增、编辑、临时授权、删除、导出。
- **角色管理**：维护角色名称、编码、数据范围（`all` / `mine`）及所绑定的菜单与按钮权限。
- **菜单管理**：维护系统菜单结构与权限标识。

**主要操作与权限**

| 按钮 | 权限码 |
|---|---|
| 新增 / 编辑 / 删除用户 | `sys:user:create` / `sys:user:update` / `sys:user:delete` |
| 临时授权 | `sys:user:update` |
| 分配角色 | `sys:role:assign` |
| 菜单管理 | `sys:menu:manage` |

**操作步骤**

*新增用户*

1. 在「用户管理」页签点击「新增用户」。
2. 填写用户名（创建后不可修改）、密码、姓名、手机、部门、班组，选择关联角色与状态。
3. 保存后账号即可登录，登录后按角色显示菜单与按钮。

*编辑用户*

1. 行内点击「编辑」。
2. 可修改姓名、手机、部门、班组、角色与状态；如需改密码，在「新密码」填写新值（留空表示不修改）。

*临时授权*

1. 行内点击「临时授权」（钥匙图标）。
2. 设置临时授权到期时间；到期后该账号将无法登录。
3. 清空到期时间表示取消临时授权，恢复为普通账号。

*配置角色权限*

1. 切换到「角色管理」，新建角色或编辑内置角色。
2. 设置角色名称、编码、数据范围（`all` 全部 / `mine` 仅本人）。
3. 在权限树中勾选该角色可见的**菜单**与**按钮**权限，保存。
4. 用户分配该角色后，重新登录即按新权限刷新。

*维护菜单*

1. 切换到「菜单管理」，可新增、编辑菜单名称、路径、图标、排序与权限标识。
2. 菜单变更影响所有角色，请谨慎操作。

**注意事项**

- 权限配置**以角色为唯一权威来源**，直接改用户数据不会绕过角色授权。
- 修改角色权限后，对应账号需**重新登录**（或切换标签页触发刷新）方可生效。
- 超级管理员不拥有业务菜单与业务按钮，这是设计约束，不是配置遗漏。
- 删除用户为逻辑删除，历史操作记录保留。

#### 5.10.3 操作日志（`/system/logs`，权限 `sys:log:list`）

**功能说明**：审计查询系统内的关键操作记录，用于追溯责任与排查异常。

**操作前提**：超级管理员默认具备；领导被单独授予该菜单与查询权限，仅可查看，不能修改或删除日志。

**界面说明**

- 搜索条件：操作人、操作模块、操作类型、时间范围、关键字。
- 表格列：操作时间、操作人、模块、操作类型、操作内容、IP 地址、结果。
- 点击行可打开详情抽屉查看完整请求信息与结果。

**操作步骤**

1. 设置时间范围与操作人/模块等条件，点击「查询」。
2. 点击目标行查看详情。
3. 使用「导出」将筛选结果导出为 Excel，用于审计归档。

**注意事项**

- 日志为**只读**数据，系统不提供编辑与删除入口。
- 日志数据量较大，查询时建议限定时间范围。

#### 5.10.4 SCADA 接入（`/system/scada`，权限 `sys:scada:config`）

**功能说明**：配置 SCADA 数据源接入参数，是「实时监控」页数据来源的系统级设置。

**操作前提**：仅超级管理员可见（`superOnly`），后端接口同样按角色硬校验。

**界面说明**

- 数据源模式（仿真 / OPC UA 等）与端点地址配置。
- 采集周期、启动方式（是否开机自动启动）。
- 连接测试与保存按钮。

**操作步骤**

1. 选择数据源模式，填写 OPC UA 端点地址。
2. 设置采集周期与是否自动启动。
3. 点击「测试连接」验证配置是否可用。
4. 点击「保存」写入配置；已运行的采集服务按新配置生效。

**注意事项**

- 修改端点前请确认网络可达，避免采集中断。
- 本页配置为全局生效，影响所有用户的实时监控数据。
- 测点本身的增删改在「实时监控 → 测点配置」中维护，不在本页。

## 6. 常见问题（FAQ）

**Q1：为什么我看不到某个菜单或某个按钮？**

菜单与按钮均按**当前账号角色绑定**动态显示。若角色未绑定对应权限，菜单入口或按钮将不显示（不是置灰）。请联系超级管理员在「系统管理 → 权限管理 → 角色管理」中调整。

**Q2：修改了角色权限，为什么账号里没变化？**

权限以角色绑定为准，修改后需**重新登录**（或切换到其他标签页再切回，触发菜单刷新）后生效。

**Q3：操作员和领导的工作台有什么不同？**

布局不同：领导是「机组运行状态 + 2×2 图表 + 右侧今日数据总览」的全局总览；操作员是「机组运行状态通栏 + 我的告警/工单/巡检/维保四张待办卡」的我的任务视图。数据范围也不同（领导 `all`、操作员 `mine`）。

**Q4：为什么操作员列表只看到部分数据？**

操作员数据范围为 `mine`（仅本人），仅展示与本人相关的工单、告警、巡检、维保等数据；领导与超管为 `all`（全部）。该过滤在查询层生效，不是前端隐藏。

**Q5：为什么超级管理员登录后没进工作台？**

超级管理员职责为系统配置，登录后**直接进入权限管理**；侧边栏仅保留「系统管理」。

**Q6：机组信息面板的「查看详情」跳转后如何找到对应设备？**

跳转携带设备 ID/编号，设备台账页会自动筛选并**高亮**命中行（浅蓝底 + 左侧蓝条）。

**Q7：告警为什么显示「待指派」而不是「未处理」？**

「待指派」表示该告警**未闭环且尚未关联维修工单**，需先执行「维修处理」生成工单后才会进入未处理/处理中状态。

**Q8：表格数据想导出或自定义列怎么办？**

列表右上角提供「导出」（导出 Excel）、「列设置」（自定义显示列）与「刷新」按钮。

**Q9：调度指令为什么没有「执行完毕」按钮？**

需同时满足：审核状态为**已通过**、执行状态为**待执行**，且当前账号为**被指派执行人**或具备 `dispatch:execute` 权限。待审批或已驳回的指令不显示该按钮。

**Q10：调度指令审核驳回后还能继续执行吗？**

不能。驳回即流程终止，需重新创建指令。

**Q11：实时监控为什么看不到「测点配置」页签？**

测点配置属管理职能，需具备任一 `scada:point:*` 权限（默认仅领导）。无权限时该页签**不渲染**。

**Q12：实时监控提示「数据缺失」怎么办？**

说明有测点超过 5 分钟未更新。请先确认 SCADA 接入配置与采集服务是否运行，再检查网络与 OPC 端点；可点击「刷新」查看最新状态。

**Q13：登录后提示「长时间未操作已退出登录」是什么原因？**

登录凭证已过期或失效，系统出于安全考虑自动退出。重新登录即可；若频繁出现，请联系管理员检查账号状态。

**Q14：页面提示「无法连接服务器，请检查网络或稍后重试」怎么办？**

前端无法连通后端服务。请检查网络与后端服务状态；若为本地开发环境，确认前后端端口一致（默认前端 5173、后端 8000）。
